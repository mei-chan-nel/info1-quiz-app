QUESTION 161#center_style_original_202608_0130

Wi-Fiアクセスポイントを利用者の端末が識別し、接続先一覧から選ぶために使うネットワーク名を次から選べ。

  1. 0

    WPA3

  2. 1

    MACアドレス

  3. 2

    SSID

  4. 3

    DNS

正答と解説を確認

正答2. SSID

解説

SSIDは無線LANを識別する名称で、端末は周囲のSSIDを一覧表示して接続先を選べる。WPA3は無線LANの認証・暗号化に関するセキュリティ規格で、利用者へ示すネットワーク名とはいえない。

QUESTION 162#center_style_original_202608_0131

同じ世代のWi-Fi機器を屋内で使う場合の、5 GHz帯と2.4 GHz帯の一般的な特徴の組合せを次から選べ。

  1. 0

    5 GHz帯は壁などの障害物で減衰しにくく、2.4 GHz帯より離れた部屋まで届きやすい

  2. 1

    2.4 GHz帯は旧式機器専用で現在のWi-Fiには使われず、5 GHz帯だけが接続に利用される

  3. 2

    5 GHz帯は広い帯域と少ない干渉を得やすいが、2.4 GHz帯より障害物越しでは減衰しやすい

  4. 3

    二つの周波数帯は利用チャネルや干渉源が同じなので、設置場所による使い分けは必要ない

正答と解説を確認

正答2. 5 GHz帯は広い帯域と少ない干渉を得やすいが、2.4 GHz帯より障害物越しでは減衰しやすい

解説

機器・規格・混雑状況にもよるが、5 GHz帯は高速化に使えるチャネルを得やすく、到達性では2.4 GHz帯が有利な場合が多い。一般に周波数が高い5 GHz帯は壁などで減衰しやすく、2.4 GHz帯より必ず遠距離へ届くわけとはいえない。

QUESTION 163#center_style_original_202608_0148

WebブラウザがHTTPSでページを取得するときに使われる、HTTP、TCP、IPの役割の組合せを次から選べ。

  1. 0

    HTTPは要求・応答の形式、TCPは順序制御や再送を伴うバイト列転送、IPは宛先ネットワークへのパケット配送

  2. 1

    HTTPは名前解決、TCPは経路選択、IPはWebページの要求・応答を担当する

  3. 2

    HTTPは通信の暗号化、TCPは宛先IPアドレスへの配送、IPは順序制御と再送を担当する

  4. 3

    HTTPはIPアドレスによる配送、TCPはWebの要求・応答、IPは到着順の保証を担当する

正答と解説を確認

正答0. HTTPは要求・応答の形式、TCPは順序制御や再送を伴うバイト列転送、IPは宛先ネットワークへのパケット配送

解説

階層ごとに役割を追うと混同しにくい。HTTPはWebの要求と応答、TLSはその通信の暗号化と相手確認、TCPは順序や再送を伴う転送、IPはアドレスに基づく配送を担う。一つの通信でも、異なる層の仕組みが役割分担している。

QUESTION 164#center_style_original_202608_0170

端末の設定画面に、IPv4アドレスが2進数で「11000000 10101000 00001010 00011001」と表示された。8ビットずつ10進数に直し、ドットで区切った表記を次から選べ。

  1. 0

    192.168.10.25

  2. 1

    192.168.10.19

  3. 2

    192.168.5.25

  4. 3

    192.84.10.25

正答と解説を確認

正答0. 192.168.10.25

解説

IPv4のドット付き10進表記では、32ビットを左から8ビットずつ四つに分ける。各組は0～255の数になり、128、64、32、16、8、4、2、1のうち、1が立つ位置の値を足して変換する。

QUESTION 165#center_style_original_202608_0191

学校の一つの校舎内や一つのオフィス内のように、地理的に限られた範囲で機器を接続するネットワークを表す略語を次から選べ。

  1. 0

    WAN

  2. 1

    LAN

  3. 2

    WWW

  4. 3

    VPN

正答と解説を確認

正答1. LAN

解説

LANはLocal Area Networkの略で、建物内など限定された範囲の機器を接続するネットワークを指す。WANはWide Area Networkの略で、離れた拠点間など広い地理的範囲を結ぶネットワークを指すといえる。

  2. 1

QUESTION 167#center_style_original_202608_0207

TCP/IPネットワークで用いるIPアドレスの役割として最も適当なものを次から選べ。

  1. 0

    IPアドレスは機器の製造時に固定され、接続するネットワークが変わっても同じ製造番号として使う

  2. 1

    通信内容を第三者に読まれないよう暗号化する共通鍵となる

  3. 2

    ネットワーク上のインタフェースを論理的に識別し、パケットの送信元・宛先を指定する

  4. 3

    機器が置かれた場所の緯度と経度を誤差なく示す座標となる

正答と解説を確認

正答2. ネットワーク上のインタフェースを論理的に識別し、パケットの送信元・宛先を指定する

解説

IPアドレスはIPネットワーク上のインタフェースを論理的に識別し、ルータが宛先へパケットを転送する際に用いられる。製造時に付与されることが多いリンク層の識別子はMACアドレスである。IPアドレスは設定や接続先に応じて変わり得るといえる。

QUESTION 168#center_style_original_202608_0209

IPv4とIPv6のIPアドレスについて、アドレスのビット数と表せる組合せの関係を説明したものとして最も適当なものを次から選べ。

  1. 0

    IPv4は32ビット、IPv6は128ビットであり、IPv6の方が表せるアドレスの組合せが多い

  2. 1

    IPv4は128ビット、IPv6は32ビットであり、IPv4の方が表せる組合せが多い

  3. 2

    IPv4もIPv6も32ビットであり、表せる組合せの数は同じである

  4. 3

    IPアドレスのビット数は送信するファイルの大きさに応じて毎回変化する

正答と解説を確認

正答0. IPv4は32ビット、IPv6は128ビットであり、IPv6の方が表せるアドレスの組合せが多い

解説

IPv4アドレスは32ビット、IPv6アドレスは128ビットで表す。nビットで表せる組合せは2ⁿ通りなので、IPv6はIPv4より多くのアドレスを表せる。IPアドレスの役割は、ネットワーク上の通信相手を識別することである。

QUESTION 169#center_style_original_202608_0210

利用者がブラウザへホスト名www.mei-chan-nel.comを入力し、対応するWebサーバへ接続しようとする。DNSが主に担う処理を次から選べ。

  1. 0

    同じLAN内で、宛先に応じてスイッチングハブの転送先を決める

  2. 1

    端末へ未使用のIPアドレスなどのネットワーク設定を自動的に割り当てる

  3. 2

    ドメイン名に対応するIPアドレスを問い合わせて取得する

  4. 3

    宛先IPアドレスを基に、異なるネットワーク間でパケットを中継する

正答と解説を確認

正答2. ドメイン名に対応するIPアドレスを問い合わせて取得する

解説

DNSはドメイン名に対応するIPアドレスを問い合わせて取得する名前解決を担う。その後、IPがその宛先への配送を担い、同じLAN内で機器の番号を学習してデータを中継するのはスイッチの役割である。

QUESTION 170#center_style_original_202608_0262

インターネットで用いられるパケット交換方式の説明として最も適当なものを次から選べ。

  1. 0

    通信中は送受信者間の専用経路を確保し続ける回線交換方式

  2. 1

    データを小さな単位に分け、宛先などの制御情報を付けて転送するパケット交換方式

  3. 2

    メッセージ全体を中継点で保存してから次へ送るが、小さなパケットには分割しない方式

  4. 3

    一つの送信を全端末へ同時配信し、宛先を指定しない放送方式

正答と解説を確認

正答1. データを小さな単位に分け、宛先などの制御情報を付けて転送するパケット交換方式

解説

パケット交換では、データを小さな単位に分け、宛先などの制御情報を付けて転送する。複数の通信が回線を共有できる点が特徴である。通信中に専用経路を確保し続ける回線交換とは区別する。
