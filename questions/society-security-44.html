QUESTION 431#center_style_original_202608_0249

英大文字A～Zを循環させ、平文の各文字をアルファベット順で2文字後ろへ置き換えるシーザー暗号を用いる。平文CATを暗号化した文字列を次から選べ。

  1. 0

    DBU

  2. 1

    EAT

  3. 2

    ECV

  4. 3

    YAR

正答と解説を確認

正答2. ECV

解説

シーザー暗号では、各文字を同じ数だけ循環してずらす。末尾のZを越えたらAへ戻る点に注意する。復号するときは暗号化と反対向きに同じ数だけ戻す。

QUESTION 432#center_style_original_202608_0251

情報セキュリティの三要素と、その性質を高める対策の組合せのうち、誤っているものを次から選べ。

  1. 0

    機密性：利用者認証とアクセス権によって、許可された人だけが情報を参照できるようにする

  2. 1

    可用性：情報を暗号化して、復号鍵を持たない人に内容を読ませないようにする

  3. 2

    完全性：デジタル署名や変更履歴によって、意図しない改ざんを検知・追跡できるようにする

  4. 3

    可用性：冗長化や復元可能なバックアップによって、障害時にも利用・復旧しやすくする

正答と解説を確認

正答1. 可用性：情報を暗号化して、復号鍵を持たない人に内容を読ませないようにする

解説

機密性は許可のない閲覧の防止、完全性は不正な変更の防止・検出、可用性は必要時の利用を表す。対策が主にどの性質へ効くかで対応付ける。

QUESTION 433#center_style_original_202608_0253

土壌水分センサの測定値に応じて自動でかん水するシステムを農地へ導入する。センサ故障や通信異常による過剰かん水を抑える設計として最も適当なものを次から選べ。

  1. 0

    一回でも極端な乾燥値が届けば、停止条件を設けず最大量の水を流し続ける

  2. 1

    校正ずれや欠測は起こらないと仮定し、受信値を全て無条件に正しいとみなす

  3. 2

    制御値と操作履歴を保存せず、誤作動後に原因を追跡できないようにする

  4. 3

    複数回の測定、妥当範囲、他センサとの整合を確認し、異常時は安全側に停止して通知する

正答と解説を確認

正答3. 複数回の測定、妥当範囲、他センサとの整合を確認し、異常時は安全側に停止して通知する

解説

時間的・空間的な冗長確認と範囲検査で異常を検出し、フェイルセーフに停止・通知すれば危険な制御を抑えられる。単一の外れ値へ無期限に反応すると、故障時に浸水や作物被害を拡大する。上限と停止条件が必要である。

QUESTION 434#center_style_original_202608_0267

生徒が授業で描いたオリジナルのイラストを完成させた。まだ公表しておらず、著作権の登録や©表示も行っていない。この時点の著作権に関する説明を次から選べ。

  1. 0

    著作権登録原簿へ登録するまでは著作権が発生しない

  2. 1

    イラストを創作した時点で、登録や©表示をしなくても著作権が発生している

  3. 2

    SNSへ最初に投稿した時点で初めて著作権が発生する

  4. 3

    特許庁へイラストを出願し、審査を受けた時点で著作権が発生する

正答と解説を確認

正答1. イラストを創作した時点で、登録や©表示をしなくても著作権が発生している

解説

日本の著作権は、権利を得るための登録などを必要としない無方式主義を採る。したがって、創作した表現が著作物に当たるなら、未公表で©表示がなくても、イラストを完成させた時点で著作権が発生する。登録制度が存在することと、登録が権利発生の条件であることは別である。

QUESTION 435#center_style_original_202608_0268

市販の電子書籍を購入した生徒が、自分で読むために端末へ保存した後、そのページ画像を誰でも閲覧できるSNSへ投稿した。著作権者の許諾はなく、ほかの権利制限規定に該当する事情もない。この投稿に関する説明として最も適当なものを次から選べ。

  1. 0

    購入者が自分用に作成した複製物なので、投稿先の公開範囲や閲覧者数にかかわらず私的使用の範囲に含まれる

  2. 1

    自分用の保存と一般公開は別の行為であり、この投稿は私的使用の範囲を外れて公衆送信に関する権利が問題になる

  3. 2

    代金を受け取らない投稿であれば、誰でも閲覧できるSNSであっても著作権者の許諾を得ずに公開できる

  4. 3

    書名と著者名を投稿文へ明記すれば、ページ画像そのものを一般公開することについても許諾を得た扱いになる

正答と解説を確認

正答1. 自分用の保存と一般公開は別の行為であり、この投稿は私的使用の範囲を外れて公衆送信に関する権利が問題になる

解説

私的使用のための複製は、個人的・家庭内などの限られた範囲で使うことを目的とする。自分用に端末へ保存する行為と、ページ画像を誰でも見られるSNSへ投稿する行為は分けて考える必要がある。後者は限られた範囲を超える公衆への送信であり、問題文の条件では私的使用として扱えない。

QUESTION 436#center_style_original_202608_0269

日本での著作権と特許権の発生に関する説明として最も適当なものを次から選べ。

  1. 0

    著作権と特許権は、作品や発明を最初に販売した時点で、出願や審査を経ず同じように発生する

  2. 1

    著作権は特許庁への出願と審査を経て発生するが、特許権は発明の完成時に手続なしで発生する

  3. 2

    著作権は著作物の創作時に方式を要せず発生し、特許権は特許庁での設定登録によって発生する

  4. 3

    特許権は発明を思い付いた時点で手続なしに発生し、登録後も期間の制限を受けず存続する

正答と解説を確認

正答2. 著作権は著作物の創作時に方式を要せず発生し、特許権は特許庁での設定登録によって発生する

解説

著作権は創作と同時に原則自動発生する一方、特許権は出願・審査を経て特許料が納付され、設定登録されることで発生する。著作権は販売を要件とせず、特許権は発明の販売だけで自動発生せず出願・審査・設定登録が必要である。

QUESTION 437#center_style_original_202608_0270

日本で、個人の実名で公表された一般的な著作物について、著作権の保護期間の原則を次から選べ。

  1. 0

    著作者の生存期間と、原則として死後70年を経過するまで

  2. 1

    創作から一律20年を経過するまで

  3. 2

    著作者の死後20年を経過するまで

  4. 3

    著作物が公表されてから一律70年を経過するまで

正答と解説を確認

正答0. 著作者の生存期間と、原則として死後70年を経過するまで

解説

保護期間は著作物や著作者の扱いによって起算点が異なる。この問題のような実名の個人著作物は原則として著作者の死後70年で、単純に創作日・公表日から数える問題ではない。例外を避けるため、問題文の著作者と公表形態を確認する。

QUESTION 438#center_style_original_202608_0271

著作物の複製について、日本の著作権法上の「私的使用のための複製」には当たらないものを次から選べ。

  1. 0

    会社が業務研修に使うため、書籍の章を複製して社員全員へ配布する

  2. 1

    本人が自宅で、自分だけの学習に使うため購入した参考書の必要部分を複製する

  3. 2

    家族内で見るため、本人が適法に入手した写真を家庭の機器で複製する

  4. 3

    本人が通勤中に聴くため、適法に購入した音源を自分の端末用に複製する

正答と解説を確認

正答0. 会社が業務研修に使うため、書籍の章を複製して社員全員へ配布する

解説

会社の業務目的で社員全員へ配布する複製は、個人的・家庭内その他これに準ずる限られた範囲での使用とはいえない。個人的な学習だけに使い、使用者本人が自宅で実施する複製は、除外事情がなければ私的使用の範囲に当たり得る。

QUESTION 439#center_style_original_202608_0272

顧客データの氏名を重複しない乱数IDへ置き換え、IDと氏名の対応表を組織内の別の場所に保管した。氏名をIDに置き換えた後のデータに関する説明として最も適当なものを次から選べ。

  1. 0

    氏名を重複しない乱数IDへ置き換えれば、対応表や識別につながる他の属性が残っていても匿名データになる

  2. 1

    対応表を使えば本人を識別できるため、匿名化されたとはいえず、置換後データと対応表の双方にアクセス制御が必要である

  3. 2

    乱数IDは暗号鍵と同じように本人との関係を隠すため、IDと氏名の対応表はアクセス制御せず共有できる

  4. 3

    氏名の欄を乱数IDへ置き換えれば、利用目的や提供範囲を検討せず、置換後データを一般公開できる

正答と解説を確認

正答1. 対応表を使えば本人を識別できるため、匿名化されたとはいえず、置換後データと対応表の双方にアクセス制御が必要である

解説

匿名化されたデータとは、少なくとも氏名を隠しただけのデータを指すものではない。この例では対応表によってIDと氏名を結び付けられるため、本人を識別できる状態が残っている。法令上の「仮名加工情報」を扱うための加工要件が示された問題ではないので、その用語へ機械的に当てはめず、再識別の可能性とアクセス管理から判断する。

QUESTION 440#center_style_original_202608_0279

送信者Xが大容量データを受信者Yだけに読めるよう送るため、公開鍵暗号と共通鍵暗号を組み合わせるハイブリッド暗号を用いる。処理として最も適当なものを次から選べ。

  1. 0

    大容量データを一時的な共通鍵で暗号化し、その共通鍵をYの公開鍵で暗号化して送る

  2. 1

    Yの秘密鍵をXへ平文で送り、その秘密鍵を共通鍵として全データの暗号化に使う

  3. 2

    大容量データをXの公開鍵で暗号化し、YがXの秘密鍵を入手して復号する

  4. 3

    共通鍵を暗号化せずデータと同じ場所へ公開し、Yだけが見つけられることを期待する

正答と解説を確認

正答0. 大容量データを一時的な共通鍵で暗号化し、その共通鍵をYの公開鍵で暗号化して送る

解説

高速な共通鍵暗号でデータ本体を処理し、共通鍵だけをYの公開鍵で保護すれば、Yは自分の秘密鍵で共通鍵を得て復号可能になる。Yの秘密鍵はYだけが保持すべきで、Xへ送れば公開鍵暗号の安全性とYの本人性を損なうといえる。
