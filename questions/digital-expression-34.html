QUESTION 331#center_style_original_202608_0312

5×5画素の白黒2階調画像を、左上から行単位で走査し、白を0、黒を1として1画素1ビットで隙間なく保存する。最終画素を保存した時点で使う総ビット数を次から選べ。

  1. 0

    25ビット

  2. 1

    5ビット

  3. 2

    10ビット

  4. 3

    50ビット

正答と解説を確認

正答0. 25ビット

解説

ビット単位で隙間なく保存するなら、総ビット数は画素数×1画素のビット数で求める。バイト単位の保存では端数を埋めるビットが必要になる場合がある。

QUESTION 332#center_style_original_202608_0313

5×5画素の4階調画像を、各画素に必要な最小限の固定長ビット数を使って隙間なく保存する。付加情報を無視したデータ量を次から選べ。

  1. 0

    25ビット

  2. 1

    40ビット

  3. 2

    100ビット

  4. 3

    50ビット

正答と解説を確認

正答3. 50ビット

解説

k階調を固定長で表す最小ビット数は2ⁿ≧kとなるnである。4階調は2ビットなので、25画素では50ビットとなる。

QUESTION 333#center_style_original_202608_0314

画素数が同じ二つの濃淡画像を、各画素に必要な最小の固定長ビット数で隙間なく保存する。画像Aは2階調で全体が25ビット、画像Bは全体が75ビットであった。画像Bの階調数を次から選べ。

  1. 0

    3階調

  2. 1

    4階調

  3. 2

    8階調

  4. 3

    16階調

正答と解説を確認

正答2. 8階調

解説

既知の画像から1画素当たりビット数を逆算し、2のその乗で階調数を求める。画素数が同じという条件が、この比較に必要である。

QUESTION 334#center_style_original_202608_0315

CPUの構成要素のうち、加算や大小比較などの計算を行うものを次から選べ。

  1. 0

QUESTION 335#center_style_original_202608_0316

CPUが主記憶上の機械語命令を繰り返し実行するときの基本的な命令実行サイクルの順序を次から選べ。

  1. 0

    命令の解読→命令の取出し→命令の実行

  2. 1

    命令の取出し→命令の実行→命令の解読

  3. 2

    命令の取出し→命令の解読→命令の実行

  4. 3

    命令の実行→命令の解読→命令の取出し

正答と解説を確認

正答2. 命令の取出し→命令の解読→命令の実行

解説

CPUの基本サイクルは、主記憶から命令を取り出すフェッチ、命令の意味を調べるデコード、その指示に従う実行の順である。実行後は次の命令へ進み、この循環を高速に繰り返す。

QUESTION 336#center_style_original_202608_0322

標本化周波数12,000 Hzで音声を標本化する。ここでは標本化定理に従い、標本化周波数を音声に含まれる最高周波数の2倍以上にするものとする。この条件で扱える最高周波数の上限を次から選べ。

  1. 0

    12,000 Hz

  2. 1

    24,000 Hz

  3. 2

    6,000 Hz

  4. 3

    4,000 Hz

正答と解説を確認

正答2. 6,000 Hz

解説

標本化周波数を最高周波数の2倍以上にするという条件から、12,000≧2fと置く。両辺を2で割るとf≦6,000 Hzとなるため、扱える最高周波数の上限は6,000 Hzである。条件を満たす値の一例ではなく、上限を問われている点に注意する。

QUESTION 337#center_style_original_202608_0323

PCM音声の量子化ビット数を8ビットから16ビットへ増やし、標本化周波数・録音時間・チャンネル数は変えない。非圧縮データ量と1標本の量子化段階数の変化を次から選べ。

  1. 0

    データ量は256倍、段階数は2倍

  2. 1

    データ量も段階数も2倍

  3. 2

    データ量は2倍、段階数は256倍

  4. 3

    データ量も段階数も変わらない

正答と解説を確認

正答2. データ量は2倍、段階数は256倍

解説

非圧縮PCMのデータ量は量子化ビット数に比例するので、8から16ビットなら2倍である。一方、段階数は2のビット数乗で決まり、2¹⁶÷2⁸＝256倍となる。ビット数と段階数は同じ割合では増えない。

QUESTION 338#center_style_original_202608_0324

標本化周波数44,100 Hz、量子化16ビット、ステレオ2チャンネルで10秒間録音した。ヘッダを無視した非圧縮PCM音声のデータ量をビット単位で表したものを次から選べ。

  1. 0

    1,764,000ビット

  2. 1

    7,056,000ビット

  3. 2

    14,112,000ビット

  4. 3

    28,224,000ビット

正答と解説を確認

正答2. 14,112,000ビット

解説

PCMの総ビット数は標本化周波数×量子化ビット数×チャンネル数×秒数で求める。バイトを問われた場合だけ、最後に8で割る。

QUESTION 339#center_style_original_202608_0325

8,000 Hz、8ビット、モノラルで5秒間のPCM音声を、同じ値が連続する長さを記録するランレングス法で圧縮する。最も圧縮効果が高くなりやすい音声を次から選べ。

  1. 0

    標本値がほぼ毎回変化する打楽器の演奏

  2. 1

    音量と音高が細かく変化し続ける歌声

  3. 2

    全標本が同じ値となる5秒間の無音

  4. 3

    ホワイトノイズのように標本値が不規則に変化する音

正答と解説を確認

正答2. 全標本が同じ値となる5秒間の無音

解説

同じ標本値が長く連続するため、一つの値と長い繰返し回数で表せ、ランレングス法と相性がよい。標本値が頻繁に変わると短いランが多数でき、値と長さの記録が増えて圧縮効果が小さい。

QUESTION 340#center_style_original_202608_0326

元データと復元データの一文字の違いも許されない用途として、非可逆圧縮の使用が最も不適当なものを次から選べ。

  1. 0

    配信量を減らすため、視聴上許容できる品質を確認して保存する動画データ

  2. 1

    実行結果を変えないよう完全一致で保存するプログラムのソースコード

  3. 2

    表示用途に必要な画質を定め、通信量との均衡を取って保存するWeb掲載写真

  4. 3

    聴感上の違いが許容範囲かを確認し、通信量を抑えて配信する音楽データ

正答と解説を確認

正答1. 実行結果を変えないよう完全一致で保存するプログラムのソースコード

解説

ソースコードは一文字の変更でも構文や意味が変わり得るため、元データを完全復元できる可逆圧縮が必要である。動画は人の知覚上目立ちにくい情報を削る非可逆圧縮が広く使われ、許容品質を設定できる用途である。
