QUESTION 091#center_style_original_202608_0214

同じ人数の二つの学年について、1か月の小遣い額の平均を学年別に比較したい。平均値の差を読み取りやすく示すグラフを次から選べ。

  1. 0

    二つの平均値を合計100%の内訳とみなす円グラフ

  2. 1

    学年別の平均値を同じ尺度の棒の高さで示す並列棒グラフ

  3. 2

    学年別の小遣い総額だけを上下に積み上げる積み上げ棒グラフ

  4. 3

    平均値を横軸と縦軸の両方に配置した散布図

正答と解説を確認

正答1. 学年別の平均値を同じ尺度の棒の高さで示す並列棒グラフ

解説

同一尺度上に学年ごとの平均を並べれば、棒の高さから二つの平均値を直接比較可能になる。円グラフは全体に対する構成比を示すのに向く。独立した二つの平均値を合計100%の内訳として扱う根拠はない。

QUESTION 092#center_style_original_202608_0242

大雨で避難指示が発表された。発表から短時間で、同じ内容を地域の多数の住民へ届けるために特に必要なメディアの性質を次から選べ。

  1. 0

    情報を長期間保存でき、後から語句で探し出せること

  2. 1

    受信者が都合のよい時刻に閲覧し、個別に返信できること

  3. 2

    新しい情報をすぐ伝え、一度の発信で多くの人へ届けられること

  4. 3

    閲覧者を限定し、内容を第三者に知られにくくできること

正答と解説を確認

正答2. 新しい情報をすぐ伝え、一度の発信で多くの人へ届けられること

解説

メディアは目的から必要な性質を選ぶ。緊急時は速報性と同報性、記録を後で調べる用途では保存性と検索性、個別相談では双方向性というように、利用場面で優先順位が変わる。

QUESTION 093#center_style_original_202608_0243

一人の発信者が多数の受信者へ情報を送り、受信者は発信者と同時刻でなくても内容を受け取れる非同期的な1対多コミュニケーションの例を次から選べ。

  1. 0

    二人が電話を使い、互いの声を聞きながら同じ時刻に会話を進める

  2. 1

    社員が一人の上司だけを宛先に指定し、業務報告のメールを個別に送る

  3. 2

    配信者が公開したオンデマンド講義動画を、受講者が各自の都合のよい時刻に視聴する

  4. 3

    放送局が多数の視聴者へ生中継し、視聴者が放送時刻に合わせて同時に見る

正答と解説を確認

正答2. 配信者が公開したオンデマンド講義動画を、受講者が各自の都合のよい時刻に視聴する

解説

一人の配信者から多数の受講者へ提供され、視聴時刻を受信者が選べるので、非同期的な1対多に該当する。電話の会話は通常、両者が同時に参加する同期的な1対1コミュニケーションと捉えられる。

QUESTION 094#center_style_original_202608_0244

活版印刷などの印刷技術が普及したことによる情報伝達上の変化として最も適当なものを次から選べ。

  1. 0

    記憶を外部に残せなくなり、情報は口頭だけで伝えるようになった

  2. 1

    遠隔地の全ての受信者へ、印刷と同時に情報が届くようになった

  3. 2

    同じ内容の文書を多数複製し、手書き中心の時代より広い範囲へ伝えやすくなった

  4. 3

    個人が電子ネットワークを使って世界へ動画を即時配信できるようになった

正答と解説を確認

正答2. 同じ内容の文書を多数複製し、手書き中心の時代より広い範囲へ伝えやすくなった

解説

版を利用して同じ内容を効率よく多数作成可能なので、書籍や新聞などを通じた知識の保存・普及が進んだ。印刷物は情報を文字や図として外部に記録・保存する媒体であり、口頭伝達だけに限定するものとはいえない。

QUESTION 095#center_style_original_202608_0252

ブレーンストーミングで得た多数の短いアイデアを、意味の近さでグループ化し、グループ同士の関係を図にして課題の構造を整理したい。用いる手法を次から選べ。

  1. 0

    作業の開始・終了時期を横棒で表すガントチャート

  2. 1

    要因間の因果関係を矢印で検討する連関図法

  3. 2

    工程の所要時間と前後関係から日程を計算するPERT

  4. 3

    カードを内容の近さでまとめ、見出しと関係を整理するKJ法

正答と解説を確認

正答3. カードを内容の近さでまとめ、見出しと関係を整理するKJ法

解説

アイデアをカード化し、意味の近さでグループ化して全体構造を示す手法である。ガントチャートは日程と進捗の管理に向き、短文カードの親和性による分類手法とはいえない。

QUESTION 096#center_style_original_202608_0258

「料理が予定時刻までに完成しない」という結果についてフィッシュボーン図で原因候補を整理する。原因候補ではなく、原因に対する改善策を述べたものを次から選べ。

  1. 0

    冷凍材料の解凍開始が遅く、調理開始まで待ち時間が生じた

  2. 1

    工程順を組み替え、重要な加熱時間をタイマーで管理する

  3. 2

    同時に使える加熱器具が一台しかなく、工程が待ち状態になった

  4. 3

    各工程の担当者が決まっておらず、作業開始が重複・遅延した

正答と解説を確認

正答1. 工程順を組み替え、重要な加熱時間をタイマーで管理する

解説

原因分析では、『なぜ起きたか』を表す原因候補と、『どう変えるか』を表す改善策を分ける。フィッシュボーン図にはまず検証可能な原因候補を置き、事実確認で原因を絞った後に対策を考えると、思い込みによる対策を避けやすい。

QUESTION 097#center_style_original_202608_0259

フィッシュボーン図を用いて問題の原因候補を列挙・分類した後に行うこととして最も適当なものを次から選べ。

  1. 0

    図に書き込んだ時点で全て事実と確定し、追加の調査は行わない

  2. 1

    最初に思い付いた原因だけを残し、根拠を調べず他の候補を削除する

  3. 2

    原因の分類が終われば問題は解決したとみなし、対策後の評価を省略する

  4. 3

    各原因候補を観測データや現場確認で検証し、影響の大きい原因へ対策を行って効果を測る

正答と解説を確認

正答3. 各原因候補を観測データや現場確認で検証し、影響の大きい原因へ対策を行って効果を測る

解説

図は仮説を整理する道具なので、事実との照合で真因を絞り、対策の実施後に指標を再測定して改善を確かめる。図に挙げた項目は原因候補であり、記載しただけでは因果関係や影響の大きさが確認されたことにならないといえる。

QUESTION 098#center_style_original_202608_0260

「製品の不良」を結果として示すフィッシュボーン図で、大骨を「人・機械・材料・方法」に分けた。この大骨の役割を次から選べ。

  1. 0

    原因候補を観点別の大分類に整理し、見落としを減らす

  2. 1

    実施する改善策を優先順位どおりに並べ、完了日を管理する

  3. 2

    原因候補が事実だと検証済みであることを示す

  4. 3

    問題の発生件数を時系列の棒グラフとして表す

正答と解説を確認

正答0. 原因候補を観点別の大分類に整理し、見落としを減らす

解説

フィッシュボーン図では、大骨に原因を探す観点、小骨に具体的な原因候補を置く。対策の日程や優先順位は、原因を整理した後に別の表などで管理する。

QUESTION 099#center_style_original_202608_0302

タイトル、二段階の見出し、本文からなる調査報告書を読みやすく整える。文字の階層を示す設計として最も適当なものを次から選べ。

  1. 0

    同じ役割には同じ大きさ・太さ・間隔を使い、タイトルから本文へ段階的に差を付け、本文の行間も確保する

  2. 1

    見出しと本文を同じ大きさにそろえ、見出しの前後だけ空行を入れずに文章を連続させる

  3. 2

    本文をタイトルより大きな太字にし、本文の情報量が多いことを文字の強さで表す

  4. 3

    各見出しへ異なる書体と色を割り当て、同じ階層でもページごとに見え方を変える

正答と解説を確認

正答0. 同じ役割には同じ大きさ・太さ・間隔を使い、タイトルから本文へ段階的に差を付け、本文の行間も確保する

解説

視覚的階層は、目立たせる量を増やすほどよいわけではない。大きさ・太さ・余白など少数の手掛かりを一貫して使い、同じ役割を同じ見え方にすることで素早く構造を読める。

QUESTION 100#center_style_original_202608_0303

実験または調査の内容を第三者が理解し、結果の根拠を評価できる報告書の基本構成を次から選べ。

  1. 0

    結論・結果・目的・方法と並べ、考察を省略する

  2. 1

    目的・方法・結果・考察・結論

  3. 2

    結果だけを示し、目的と再現可能な方法を記載しない

  4. 3

    目的と結論だけを示し、観測結果とその解釈を区別しない

正答と解説を確認

正答1. 目的・方法・結果・考察・結論

解説

結果は観測・集計された事実、考察はその意味の解釈として分ける。方法を具体的に残すと、第三者が同じ手順を再現し、結論の根拠を評価できる。
