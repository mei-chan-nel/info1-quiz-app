QUESTION 311#center_style_original_202608_0257

各フレームのデータ量が675 KBで、一定の24 fps、長さ10分の無圧縮動画を保存する。付加情報は無視し、1 GB=1,024 MB、1 MB=1,024 KBとすると、データ量に最も近い値を次から選べ。

  1. 0

    9.49 GB

  2. 1

    9.72 GB

  3. 2

    15.8 GB

  4. 3

    9.27 GB

正答と解説を確認

正答3. 9.27 GB

解説

動画では、まず秒数×fpsで総フレーム数を求め、1フレームの量を掛ける。KBからGBへの換算は、問題文が1,000系か1,024系かを確認する。

QUESTION 312#center_style_original_202608_0265

奇数パリティビットを1個付け、受信した全ビット中の1の個数が奇数かだけを調べる。検査結果が正常だったときに言えることとして最も適当なものを次から選べ。

  1. 0

    パリティ検査に合格すれば、受信ビット列は送信時の値と一致したと判断できる

  2. 1

    単純パリティは反転数にかかわらず同じ仕組みなので、奇数個の反転も見逃す

  3. 2

    偶数個のビット反転など、検出できない誤りが残っている可能性がある

  4. 3

    検査合格はパリティビット以外の全ビットが正しいことを保証する

正答と解説を確認

正答2. 偶数個のビット反転など、検出できない誤りが残っている可能性がある

解説

偶数個の反転では1の個数の偶奇が変わらないため、正常と判定されても誤りがあり得る。単純パリティには見逃す誤りパターンがあり、合格だけで無誤りを保証できない。

QUESTION 313#center_style_original_202608_0281

10進数の0.1を10回加えるプログラムを実行したところ、計算結果が1.0と完全には一致しない場合があった。主な理由として最も適当なものを次から選べ。

  1. 0

    加算を10回行うとCPUが故障し、以後の計算結果が不規則になるため

  2. 1

    10進小数は全て2進数で有限桁に正確に表せるが、表示だけが毎回変化するため

  3. 2

    計算結果が表せる最大値を超え、整数のオーバーフローが起きたため

  4. 3

    0.1を有限桁の2進数で近似して保存するため、丸め誤差が加算で蓄積することがあるため

正答と解説を確認

正答3. 0.1を有限桁の2進数で近似して保存するため、丸め誤差が加算で蓄積することがあるため

解説

コンピュータの浮動小数点数は、限られたビット数で実数を近似して表す。10進数では有限小数でも、2進数では循環して有限桁に収まらない値があるため、保存時の丸め誤差が計算に影響することがある。小数の一致判定では、許容誤差を使う方法がある。

QUESTION 314#center_style_original_202608_0290

11桁の本体番号から所定の計算規則で1桁のチェックディジットを求め、番号の末尾へ付加する。チェックディジットの主な目的を次から選べ。

  1. 0

    番号入力時の一部の打ち間違いや桁の入替えを検出しやすくする

  2. 1

    チェックディジットだけを用いて、入力者が番号の本人だと認証する

  3. 2

    本体番号を暗号化し、番号全体を第三者が読めない状態にする

  4. 3

    チェックディジットを復号すれば、元の住所や氏名を取り出せる

正答と解説を確認

正答0. 番号入力時の一部の打ち間違いや桁の入替えを検出しやすくする

解説

本体番号から再計算した値と付加された値を比較し、方式が対象とする入力誤りを検出するために使う。計算規則が公開されていれば誰でも整合する数字を作れるため、本人だけが持つ認証要素にはならない。

QUESTION 315#center_style_original_202608_0291

チェックディジットを含む番号を入力し、所定の計算規則との一致を確認したところ検査に合格した。この結果から言えることとして最も適当なものを次から選べ。

  1. 0

    検査に合格したため、番号の各桁が元の番号と一致し、入力ミスがないことまで確認できた

  2. 1

    規則で検出できる不一致はないが、全桁の正しさや入力者本人であることまでは確認できない

  3. 2

    番号の計算規則が一致したため、その番号を入力した人が登録された本人であると確認できた

  4. 3

    チェックディジットを照合したため、番号全体が暗号化され、第三者には読めない状態になった

正答と解説を確認

正答1. 規則で検出できる不一致はないが、全桁の正しさや入力者本人であることまでは確認できない

解説

検査合格は計算規則に整合したことだけを示す。方式によっては見逃す誤りがあり、番号の所持と本人性も同一とはいえない。複数桁の変化などが偶然同じチェックディジットになる場合があり、全ての入力誤りを検出できるとは限らないといえる。

QUESTION 316#center_style_original_202608_0292

チェックディジットを計算する方式で、本体番号の各桁へ位置ごとに異なる重みを掛けて合計する設計を採用する目的として最も適当なものを次から選べ。

  1. 0

    二桁の入替え後も検査値を一致させ、転記順の違いを許容する

  2. 1

    一桁のチェックディジットに本体番号を符号化し、そこから全桁を復元する

  3. 2

    重みの列を秘密鍵として、番号全体を第三者に読めない暗号文へ変換する

  4. 3

    数字が同じでも位置によって計算への寄与を変え、隣接桁の入替えなども検出しやすくする

正答と解説を確認

正答3. 数字が同じでも位置によって計算への寄与を変え、隣接桁の入替えなども検出しやすくする

解説

別の重みにより桁位置の情報が計算結果へ反映され、単純合計では見逃しやすい桁交換を検出できる場合が増える。全ての桁で同じ重みなら入替え前後の合計は変わらない。位置ごとに重みを変える目的と逆である。

QUESTION 317#center_style_original_202608_0294

アナログ音声を1.5秒間標本化し、1秒間に8,000個の標本を得るものとする。得られる標本数を次から選べ。

  1. 0

    5,333個

  2. 1

    12,000個

  3. 2

    8,000個

  4. 3

    16,000個

正答と解説を確認

正答1. 12,000個

解説

1秒当たり8,000個の標本を1.5秒間得るので、標本数は8,000個/秒×1.5秒＝12,000個となる。時間が1.5倍になれば、一定の標本化周波数で得られる標本数も1.5倍になる。

QUESTION 318#center_style_original_202608_0295

最高周波数が2,000 Hzの帯域制限された音声を標本化する。ここでは標本化定理に従い、標本化周波数を最高周波数の2倍以上に設定するものとする。条件を満たす最小の標本化周波数を次から選べ。

  1. 0

    1,000 Hz

  2. 1

    2,000 Hz

  3. 2

    4,000 Hz

  4. 3

    3,000 Hz

正答と解説を確認

正答2. 4,000 Hz

解説

標本化定理では、帯域が制限された信号を理論上復元するため、標本化周波数を最高周波数の2倍以上にする。最高2,000 Hzなら最低4,000 Hzである。実際の機器ではフィルタの特性などを考え、余裕を持たせることが多い。

QUESTION 319#center_style_original_202608_0296

標本化周波数と録音時間を変えずに、PCM音声の1標本当たりの量子化ビット数を増やした。一般に起こる変化を次から選べ。

  1. 0

    ステレオをモノラルにすると、標本化周波数も半分になってデータ量が減る

  2. 1

    音声の再生時間が自動的に長くなり、標本の振幅精度は変わらない

  3. 2

    表現できる振幅の段階数が増え、量子化誤差を小さくしやすいが、データ量は増える

  4. 3

    ステレオをモノラルにすると量子化段階が減り、量子化雑音も小さくなる

正答と解説を確認

正答2. 表現できる振幅の段階数が増え、量子化誤差を小さくしやすいが、データ量は増える

解説

PCM音声のデータ量は、概ね『標本化周波数×量子化ビット数×チャネル数×時間』で決まる。量子化ビット数を増やすと一回の測定値を細かく表せるが、その分データ量も増える。時間方向の細かさを決める標本化周波数とは別の要素である。

QUESTION 320#center_style_original_202608_0297

デジタル画像の空間解像度に関する説明として不適切なものを次から選べ。

  1. 0

    同じ表示サイズなら、画素数が多いほど細部を表現しやすい

  2. 1

    空間解像度を上げれば、色深度が同じでも1画素で表せる色の種類が増える

  3. 2

    画素の密度や画像を構成する縦横の画素数に関係する

  4. 3

    色深度が同じでも、画素をより細かく配置できる場合がある

正答と解説を確認

正答1. 空間解像度を上げれば、色深度が同じでも1画素で表せる色の種類が増える

解説

空間解像度は画像をどれだけ細かな画素で区切るか、色深度は1画素で何色を区別できるかを表す。二つは別の性質である。
