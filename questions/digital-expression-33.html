QUESTION 321#center_style_original_202608_0298

RGB各成分を8ビットの符号なし整数で表す画像で、画素(32, 128, 255)の各成分を255から引いて色を反転した結果を次から選べ。

  1. 0

    (223, 127, 0)

  2. 1

    (223, 128, 0)

  3. 2

    (32, 127, 255)

  4. 3

    (255, 128, 32)

正答と解説を確認

正答0. (223, 127, 0)

解説

8ビット成分の反転は各値xを255−xへ写す。0と255、32と223のように、範囲の両端を基準に対応する値へ変わる。

QUESTION 322#center_style_original_202608_0299

横1,920画素、縦1,080画素で、1画素をRGB各8ビットの計24ビットで表す非圧縮画像がある。ヘッダや行のパディングを無視し、1 MB=1,000,000バイトとすると、1枚のデータ量に最も近い値を次から選べ。

  1. 0

    約0.62 MB

  2. 1

    約2.07 MB

  3. 2

    約24.9 MB

  4. 3

    約6.22 MB

正答と解説を確認

正答3. 約6.22 MB

解説

非圧縮画像の画素データ量は横×縦×色深度÷8で求める。MBの換算は1,000,000バイトか1,048,576バイトかを問題文で確認する。

QUESTION 323#center_style_original_202608_0304

モノラルPCM音声について、録音時間と1標本当たりの量子化ビット数を変えず、標本化周波数を4,000 Hzから8,000 Hzへ変更した。ヘッダを無視した非圧縮データ量の倍率を次から選べ。

  1. 0

    2倍

  2. 1

    0.5倍

  3. 2

    1倍

  4. 3

    4倍

正答と解説を確認

正答0. 2倍

解説

非圧縮PCMのデータ量は標本化周波数に比例する。他の条件が同じなら、周波数をk倍にすると標本数とデータ量もk倍になる。

QUESTION 324#center_style_original_202608_0305

量子化ビット数を8ビットから12ビットへ増やしたとき、1標本で表せる量子化段階数は元の何倍になるかを次から選べ。

  1. 0

    1.5倍

  2. 1

    4倍

  3. 2

    16倍

  4. 3

    256倍

正答と解説を確認

正答2. 16倍

解説

量子化段階数は2のビット数乗で増える。ビット数をdだけ増やすと段階数は2ᵈ倍になり、8から12ビットでは16倍である。

QUESTION 325#center_style_original_202608_0306

整数0から15までの16種類を、全て同じ長さの2進数で符号化する。必要な最小ビット数を次から選べ。

  1. 0

    3ビット

  2. 1

    4ビット

  3. 2

    8ビット

  4. 3

    15ビット

正答と解説を確認

正答1. 4ビット

解説

N種類を固定長で表すには2ⁿ≧Nとなる最小のnビットが必要である。0を含む16種類は0000～1111の4ビットでちょうど表せる。

QUESTION 326#center_style_original_202608_0307

横1,050画素、縦1,050画素の画像を、1画素当たり3バイトで隙間なく保存する。ヘッダやパディングを無視した画素データ量を次から選べ。

  1. 0

    1,102,500バイト

  2. 1

    2,205,000バイト

  3. 2

    9,922,500バイト

  4. 3

    3,307,500バイト

正答と解説を確認

正答3. 3,307,500バイト

解説

画像の画素データ量は、横の画素数×縦の画素数×1画素当たりのバイト数で求める。実際の画像ファイルには、形式を示すヘッダなど画素以外のデータが加わる場合があるが、この問題では指示どおり無視する。

QUESTION 327#center_style_original_202608_0308

各画素を8ビットの符号なし整数1個で表す濃淡画像について、表現できる階調数と画素値の範囲の組合せを次から選べ。

  1. 0

    8階調、0～7

  2. 1

    128階調、−64～63

  3. 2

    255階調、1～255

  4. 3

    256階調、0～255

正答と解説を確認

正答3. 256階調、0～255

解説

nビットの符号なし整数は2ⁿ通りあり、最小値0、最大値2ⁿ−1を表す。8ビットなら256通りで範囲は0～255となる。「通りの数」と「最大値」を混同しないことが大切である。

    4倍

  3. 2

    1.25倍

QUESTION 329#center_style_original_202608_0310

各画素をAビットの符号なし固定長ビット列で表し、全てのビットパターンを異なる階調へ割り当てる。表現できる階調数Bを表す式を次から選べ。

  1. 0

    B=A²

  2. 1

    B=2ᴬ

  3. 2

    B=2A

  4. 3

    B=A+2

正答と解説を確認

正答1. B=2ᴬ

解説

Aビットの各位置に0と1の2通りがあるため、全組合せは2ᴬ通りとなる。符号なしなら通常0～2ᴬ−1へ対応させる。
