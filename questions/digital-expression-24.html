QUESTION 231#center_style_original_202608_0016

ステレオ音声を標本化周波数11,025 Hz、量子化ビット数8ビットで4秒間記録する。圧縮を行わず、付加情報を含めないときのデータ量をバイトで表した値を次から選べ。

  1. 0

    44,100バイト

  2. 1

    11,025バイト

  3. 2

    88,200バイト

  4. 3

    705,600バイト

正答と解説を確認

正答2. 88,200バイト

解説

非圧縮音声のデータ量は「標本化周波数×量子化ビット数×時間×チャネル数」でまずビット単位を求める。ステレオは2チャネルであり、最後に8で割るとバイト単位になる。

QUESTION 232#center_style_original_202608_0017

6バイトのデータに2ビットの制御情報を付加した。1バイトを8ビットとするとき、全体のデータ量をビットで表した値を次から選べ。

  1. 0

    50ビット

  2. 1

    48ビット

  3. 2

    64ビット

  4. 3

    384ビット

正答と解説を確認

正答0. 50ビット

解説

異なる単位の量は、先にビットまたはバイトへ統一してから加える。6バイト＝48ビットに2ビットを加えるので50ビットになる。

QUESTION 233#center_style_original_202608_0018

データ部が8 KiB、ヘッダが64バイトのパケットがある。1 KiB＝1024バイト、1バイト＝8ビットとするとき、パケット全体のデータ量をビットで表した値を次から選べ。

  1. 0

    66048ビット

  2. 1

    65536ビット

  3. 2

    8256ビット

  4. 3

    64512ビット

正答と解説を確認

正答0. 66048ビット

解説

KiBは1,024バイトであり、kBを1,000バイトとする換算とは異なる。ヘッダも含めてバイト数を合計してから、8倍してビットへ直す。

QUESTION 234#center_style_original_202608_0019

圧縮を行わず、付加情報を含めない。1画素を8ビットで表す12×12画素のモノクロ画像のデータ量をバイトで表した値を次から選べ。

  1. 0

    48バイト

  2. 1

    288バイト

  3. 2

    144バイト

  4. 3

    1152バイト

正答と解説を確認

正答2. 144バイト

解説

非圧縮画像のデータ量は、横画素数×縦画素数×1画素当たりビット数で求める。8ビット/画素なら1画素がちょうど1バイトになる。

QUESTION 235#center_style_original_202608_0020

標本化周波数8000 Hz、量子化ビット数16ビットのモノラル音声を、圧縮せず付加情報も含めずに記録する。80000バイトの記憶領域に保存できる時間を次から選べ。

  1. 0

    10秒

  2. 1

    5秒

  3. 2

    0.625秒

  4. 3

    40秒

正答と解説を確認

正答1. 5秒

解説

保存時間は、容量÷1秒当たりのデータ量で求める。音声では標本化周波数、量子化ビット数、チャンネル数から先に1秒分を計算するとよい。

QUESTION 236#center_style_original_202608_0021

2入力の論理和（OR）について、真理値表を正しく表した説明を次から選べ。

  1. 0

    二つの入力の少なくとも一方が1のとき出力が1になる

  2. 1

    二つの入力がともに0のときだけ出力が1になる

  3. 2

    二つの入力がともに1のときだけ出力が1になる

  4. 3

    二つの入力が異なるときだけ出力が1になる

正答と解説を確認

正答0. 二つの入力の少なくとも一方が1のとき出力が1になる

解説

ORは複数条件の「少なくとも一つ」を表す。集合でいえば和集合に対応し、全入力が0のときだけ0になる。

QUESTION 237#center_style_original_202608_0030

8ビットの2進数10110101を、符号なし整数として10進数で表した値を次から選べ。

  1. 0

    181

  2. 1

    173

  3. 2

    213

  4. 3

    185

正答と解説を確認

正答0. 181

解説

2進数は、1になっている桁の重みを加える。10110101₂では2⁷、2⁵、2⁴、2²、2⁰を加えて128＋32＋16＋4＋1＝181となる。0の桁は加算しない。

QUESTION 238#center_style_original_202608_0031

2進数1010を10進数へ変換するときの位取り計算を次から選べ。

  1. 0

    1×2＋1×1＝3

  2. 1

    1×10³＋0×10²＋1×10＋0＝1010

  3. 2

    1×8＋0×4＋1×2＋0×1＝10

  4. 3

    1×16＋1×4＝20

正答と解説を確認

正答2. 1×8＋0×4＋1×2＋0×1＝10

解説

2進数の各桁の重みは右から1、2、4、8…と2倍ずつ増える。1の立っている桁の重みだけを足せば10進値になる。

QUESTION 239#center_style_original_202608_0032

4ビットの値1110の各ビットを0と1で反転する演算を行った結果を次から選べ。

  1. 0

    0010

  2. 1

    1111

  3. 2

    0001

  4. 3

    0111

正答と解説を確認

正答2. 0001

解説

NOTはビットごとに0と1を入れ替える。固定桁数を明示しないと左側の0をどこまで反転するか決まらないため、桁数の条件が重要である。

QUESTION 240#center_style_original_202608_0033

8ビットの状態コード10101100₂を、上位4ビットと下位4ビットに分けて16進数で表したものを次から選べ。

  1. 0

    9C

  2. 1

    AC

  3. 2

    AE

  4. 3

    CA

正答と解説を確認

正答1. AC

解説

16進数1桁は2進数4ビットに対応する。2進数を右端から4ビットずつ区切り、0000～1111を16進数の0～Fへ置き換えると、長いビット列を短く表せる。
