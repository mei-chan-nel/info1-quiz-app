QUESTION 371#center_style_original_202608_0434

10進小数を約分した分数で表したとき、分母の素因数が2だけなら有限桁の2進小数で正確に表せる。この条件を満たす10進小数を次から選べ。

  1. 0

    0.1

  2. 1

    0.2

  3. 2

    0.3

  4. 3

    0.25

正答と解説を確認

正答3. 0.25

解説

約分した分数の分母が2の累乗なら、有限桁の2進小数で表せる。0.25＝1/4＝1/2²は0.01₂となる。0.1＝1/10のように分母へ2以外の素因数が残る数は、2進では循環する。

QUESTION 372#center_style_original_202608_0435

標本化周波数8,000 Hz、モノラル、1秒間のPCM音声で、量子化を8ビットから12ビットへ増やした。ヘッダを無視した非圧縮データ量の増加分を次から選べ。

  1. 0

    500バイト

  2. 1

    8,000バイト

  3. 2

    4,000バイト

  4. 3

    32,000バイト

正答と解説を確認

正答2. 4,000バイト

解説

条件が同じならPCMのデータ量増加分は、標本数×増えたビット数で求める。ビットからバイトへ直すときは最後に8で割る。

QUESTION 373#center_style_original_202608_0439

入力Aが1かつ入力Bが0のときだけ出力Xが1となる論理式を次から選べ。ただし、∧はand、∨はor、¬はnotを意味する。

  1. 0

    (¬A)∧B

  2. 1

    A∨B

  3. 2

    ¬(A∧B)

  4. 3

    A∧(¬B)

正答と解説を確認

正答3. A∧(¬B)

解説

出力を1にしたい条件はA＝1かつB＝0である。B＝0を論理式の中で1として扱うには¬Bを用い、Aと¬Bの両方が1のときだけ1になるANDをとる。したがってX＝A∧(¬B)である。

QUESTION 374#center_style_original_202608_0440

制御入力Aが0のとき出力XへBを選び、Aが1のときXへCを選ぶ1ビットの選択回路がある。この入出力関係を表す論理式を次から選べ。ただし、∧はand、∨はor、¬はnotを意味する。

  1. 0

    (A∧B)∨(¬A∧C)

  2. 1

    ¬A∨(B∧C)

  3. 2

    (A∨B)∧C

  4. 3

    (¬A∧B)∨(A∧C)

正答と解説を確認

正答3. (¬A∧B)∨(A∧C)

解説

A＝0の場合は¬A＝1なので、(¬A∧B)∨(A∧C)はB∨0＝Bとなる。A＝1の場合は¬A＝0なので、0∨C＝Cとなる。Aの二つの値で指定どおりBとCを選べるため、この論理式が入出力関係を表す。
