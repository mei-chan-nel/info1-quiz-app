QUESTION 361#center_style_original_202608_0026

匿名の相談掲示板を運営する際、利用者への公開上の匿名性と、規約違反へ対処できる責任追跡性を両立させる方針を次から選べ。

  1. 0

    画面上は匿名とし、目的と保存期間を定めた必要最小限の記録を安全に管理する

  2. 1

    投稿内容と接続記録を常時公開し、一般利用者が投稿者を追跡できるようにする

  3. 2

    規約違反への事後対応より匿名性を優先し、接続記録を保存しない

  4. 3

    利用前に氏名と住所を収集し、投稿内容と結び付けて一般公開する

正答と解説を確認

正答0. 画面上は匿名とし、目的と保存期間を定めた必要最小限の記録を安全に管理する

解説

公開画面では匿名性を保ちつつ、必要最小限の記録を目的・期間を限定して安全に管理すれば、違反時の調査と両立可能になる。接続記録を一般公開すると第三者が投稿者を追跡でき、相談者を他の利用者から匿名にする目的を損なう。

QUESTION 362#center_style_original_202608_0027

SNSで「明日から市内の水道がすべて止まる」という出典不明の投稿を見た。共有前の対応として最も適当なものを次から選べ。

  1. 0

    自治体や水道局の公式情報と発信日時を確認し、確認できなければ拡散しない

  2. 1

    自分の意見と一致すれば、出典を示さず要約して投稿する

  3. 2

    多数の人が共有していれば真実と判断し、そのまま拡散する

  4. 3

    画像が添付されていれば、撮影場所や時期を確認せず信頼する

正答と解説を確認

正答0. 自治体や水道局の公式情報と発信日時を確認し、確認できなければ拡散しない

解説

断水を担当する自治体や水道局の公式発表を、対象地域と日時まで照合してから共有の可否を判断するのが適切である。自分の意見との一致は情報の正確さを保証せず、出典を省けば他者も検証しにくくなるといえる。

QUESTION 363#center_style_original_202608_0029

同じ出来事を扱う二つの記事で見出しと結論が異なっていた。情報の信頼性を評価する手順として最も適当なものを次から選べ。

  1. 0

    発信者、根拠となる一次資料、掲載日、引用範囲を比較する

  2. 1

    見出しの語調が強い記事ほど根拠が十分だと判断する

  3. 2

    自分の考えに近い記事だけを読み、他方は確認しない

  4. 3

    検索結果で上位の記事だけを正しいと判断する

正答と解説を確認

正答0. 発信者、根拠となる一次資料、掲載日、引用範囲を比較する

解説

誰がいつ発信し、どの一次資料のどの範囲を根拠にしたかを照合すれば、結論の違いを検証可能になる。強い語調は読者の注意を引く表現であって、主張を支える証拠の量や質を保証しない。

QUESTION 364#center_style_original_202608_0058

公開中のWebサーバで使用するソフトウェアについて脆弱性と修正プログラムが公表された。管理者が最初に進める対応として最も適当なものを次から選べ。

  1. 0

    攻撃の記録が見つからなければ、脆弱な版をそのまま使い続ける

  2. 1

    ファイアウォールがあればソフトウェア内部の脆弱性も消滅したと判断する

  3. 2

    修正プログラムをすぐ適用すればよいので、事前のバックアップや動作確認は行わない

  4. 3

    対象バージョンと影響範囲を確認し、バックアップを確保して修正プログラムを検証後に適用する

正答と解説を確認

正答3. 対象バージョンと影響範囲を確認し、バックアップを確保して修正プログラムを検証後に適用する

解説

脆弱性対応では、公表情報と自分の環境を照合して影響を判断し、悪用の危険と更新による障害の両方に備える。バックアップなど更新前の状態へ戻す手段を用意し、可能な範囲で動作確認をしてから速やかに修正する。ファイアウォールはソフトウェア自体の欠陥を直すものではない。

QUESTION 365#center_style_original_202608_0059

パスワードに加えて指静脈情報で本人確認を行う認証方式の説明を次から選べ。

  1. 0

    二つとも利用者が記憶する情報なので、知識要素だけの認証である

  2. 1

    指静脈情報はICカードと同じ所有物要素に分類される

  3. 2

    同じ利用者を二回確認するため、異なる要素でも単要素認証である

  4. 3

    知識要素と生体要素を組み合わせた二要素認証である

正答と解説を確認

正答3. 知識要素と生体要素を組み合わせた二要素認証である

解説

パスワードは利用者が知っている知識要素、指静脈は利用者自身の身体的特徴を使う生体要素である。異なる種類の要素を組み合わせて確認するため、この例は二要素認証に当たる。

QUESTION 366#center_style_original_202608_0060

匿名投稿を認める掲示板で誹謗中傷を減らしつつ、正当な意見表明にも配慮する運営策を次から選べ。

  1. 0

    閲覧数が多い投稿は内容にかかわらず正当とみなす

  2. 1

    匿名投稿は内容を確認せず削除し、記名投稿だけを審査の対象にする

  3. 2

    表示名が匿名なら被害は生じないとみなし、通報があっても対応しない

  4. 3

    禁止事項と通報・異議申立ての手順を明示し、投稿の文脈と程度に応じて段階的に対応する

正答と解説を確認

正答3. 禁止事項と通報・異議申立ての手順を明示し、投稿の文脈と程度に応じて段階的に対応する

解説

基準と手続を事前に示し、個別の文脈を確認して警告・非表示等を段階的に行えば、被害防止と手続的配慮を両立しやすいといえる。閲覧数は投稿の注目度を示すだけで、他者の権利を侵害していないことや内容の正当性を保証しない。

QUESTION 367#center_style_original_202608_0061

自治体がオンライン申請を導入したが、高齢者や通信環境の乏しい住民の利用率が低かった。デジタルデバイドへの対策を次から選べ。

  1. 0

    利用率の低い住民を集計から除き、格差がないものとして扱う

  2. 1

    対面窓口、端末貸与、操作支援、通信環境整備を組み合わせる

  3. 2

    画面の色数だけを増やせば、機器・通信環境・操作技能の格差も解消すると考える

  4. 3

    オンライン申請だけに統一し、利用できない住民の申請を受け付けない

正答と解説を確認

正答1. 対面窓口、端末貸与、操作支援、通信環境整備を組み合わせる

解説

申請経路、機器、技能、通信環境という複数の障壁へ対応すれば、情報技術を利用できる機会の差を縮められる。集計から除外しても利用機会の差は残り、格差を測定結果から見えなくするだけである。

QUESTION 368#center_style_original_202608_0062

次の認証方法のうち、二つの情報を使っていても認証要素の種類が一つだけであるものを次から選べ。

  1. 0

    パスワードとICカード

  2. 1

    パスワードと暗証番号

  3. 2

    ICカードと指紋

  4. 3

    パスワードと指紋

正答と解説を確認

正答1. パスワードと暗証番号

解説

パスワードも暗証番号も利用者が知っている知識要素なので、二つ使っても要素の種類は一つである。パスワードは知識要素、ICカードは所有物要素であり、異なる二種類を組み合わせている。

QUESTION 369#center_style_original_202608_0068

学校のWebサーバは、インターネットからのWeb閲覧は受け付けるが、管理操作は校内LANからだけ受け付けたい。ファイアウォールの設定として最も適当なものを次から選べ。

  1. 0

    Web閲覧と管理操作の両方を、接続元に関係なくインターネットから許可する

  2. 1

    外部からはWeb閲覧だけを許可し、管理操作は校内LANからの通信だけを許可する

  3. 2

    接続元や通信の種類を区別せず全て許可し、通信記録だけを残す

  4. 3

    校内LANからの管理操作を含めて全て拒否し、必要な例外も設けない

正答と解説を確認

正答1. 外部からはWeb閲覧だけを許可し、管理操作は校内LANからの通信だけを許可する

解説

ファイアウォールでは、通信の接続元、接続先、種類などの条件を使って、必要な通信だけを許可する。公開用のWeb閲覧と内部の管理操作では、許可する接続元が異なる。不要な通信を初めから許可しない最小限の設定が攻撃の機会を減らす。

QUESTION 370#center_style_original_202608_0069

SNSに投稿した写真を投稿者が削除した後も、その写真が検索結果に残る場合がある理由を次から選べ。

  1. 0

    SNSの削除は表示を隠す操作にすぎず、サービス上の元投稿は削除後も公開されるから

  2. 1

    検索結果はDNSサーバに画像として保存され、DNSには削除機能がないから

  3. 2

    共有先の複製や検索サービスのキャッシュなど、元の投稿とは別の場所に残ることがあるから

  4. 3

    投稿者の端末に元画像が残っていると、検索サービスへ自動的に再投稿されるから

正答と解説を確認

正答2. 共有先の複製や検索サービスのキャッシュなど、元の投稿とは別の場所に残ることがあるから

解説

元投稿の削除で操作できるのは、通常、そのサービス上で投稿者が管理するデータまでである。閲覧者の保存、転載先、検索サービスの一時保存であるキャッシュは管理主体が異なる。公開前に写り込みや位置情報、公開範囲を確認することが重要である。
