QUESTION 221#center_style_original_202608_0006

アナログ音声をデジタル化するPCM方式では、測定した音の大きさを決められた段階のいずれかで表す。この段階をより細かくする操作を次から選べ。

  1. 0

    量子化ビット数を増やす

  2. 1

    標本化周波数を上げる

  3. 2

    量子化ビット数を減らす

  4. 3

    ステレオからモノラルにする

正答と解説を確認

正答0. 量子化ビット数を増やす

解説

量子化ビット数をnビットとすると2のn乗段階を区別可能なので、ビット数を増やすと測定値をより細かく表せる。標本化周波数を上げると時間方向の測定回数は増えるが、1回の測定値の段階数は変わらない。

QUESTION 222#center_style_original_202608_0007

横1920画素、縦1080画素の画像を横方向だけ2倍に拡大し、新しい画素を補間して生成した。拡大後の画素数として最も適当なものを次から選べ。

  1. 0

    4147200画素

  2. 1

    2073600画素

  3. 2

    8294400画素

  4. 3

    3110400画素

正答と解説を確認

正答0. 4147200画素

解説

画像の総画素数は横画素数×縦画素数で求める。片方の辺だけをk倍にすれば総画素数はk倍、両方をk倍にすればk²倍になる。

QUESTION 223#center_style_original_202608_0008

同じ文字列を、互換性のない文字コードAでは1文字2バイト、文字コードBでは1文字1～4バイトで符号化する。文字コードを明示せずにバイト列だけを交換した場合に起こり得る問題として最も適当なものを次から選べ。

  1. 0

    受信側が異なる対応表でバイト列を解釈し、文字化けする

  2. 1

    文字コードBも1文字1バイトとして区切れば、元の文字列を復元できる

  3. 2

    送信文字数が分かれば、文字と符号の対応表がなくても元の文字列を復元できる

  4. 3

    送信前に可逆圧縮すれば、文字コードの違いは展開時に自動的に解消される

正答と解説を確認

正答0. 受信側が異なる対応表でバイト列を解釈し、文字化けする

解説

文字コードによって、文字とバイト列の対応や文字の区切り方が異なる。送信側と受信側で異なる文字コードを使うと、同じバイト列を別の文字として解釈し、文字化けが起こることがある。

QUESTION 224#center_style_original_202608_0009

研究データを保存する際、元のデータを完全に復元できるようにしたまま容量を減らしたい。この目的に最も適した処理を次から選べ。

  1. 0

    非可逆圧縮を行い、失われた情報を利用時に推測する

  2. 1

    暗号化を行い、暗号鍵を長くして容量を減らす

  3. 2

    可逆圧縮を行い、利用時に展開する

  4. 3

    標本化間隔を広げ、間の測定値を削除する

正答と解説を確認

正答2. 可逆圧縮を行い、利用時に展開する

解説

可逆圧縮はデータの規則性を利用して容量を減らし、展開によって元のデータを完全に復元可能になる。非可逆圧縮では一部の情報を捨てるため、展開しても元のビット列を完全には復元できない。

QUESTION 225#center_style_original_202608_0010

8ビットの符号なし2進数で表せる最大の10進数で表した値を次から選べ。

  1. 0

    256

  2. 1

    255

  3. 2

    128

  4. 3

    127

正答と解説を確認

正答1. 255

解説

nビットの符号なし整数は0から2ⁿ−1までの2ⁿ個を表す。2ⁿは最大値ではなく、表せる値の個数である。

QUESTION 226#center_style_original_202608_0011

2進数101101100011₂を16進数で表したものを次から選べ。

  1. 0

    B63

  2. 1

    C63

  3. 2

    B73

  4. 3

    B36

正答と解説を確認

正答0. B63

2進数と16進数は、4ビットと1桁がちょうど対応する。右端から4ビットずつ区切り、左端が4ビット未満なら0を補うと、桁の位置を保って変換できる。

QUESTION 227#center_style_original_202608_0012

2進数1001を10進数に変換する計算として正しいものを次から選べ。

  1. 0

    1×2³＋0×2²＋0×2¹＋1×2⁰＝9

  2. 1

    1×2²＋0×2¹＋0×2⁰＋1＝5

  3. 2

    1×2¹＋0×2⁰＋0＋1＝3

  4. 3

    1×10³＋0×10²＋0×10¹＋1×10⁰＝1001

正答と解説を確認

正答0. 1×2³＋0×2²＋0×2¹＋1×2⁰＝9

解説

基数bの位取りでは、右端からb⁰、b¹、b²…の重みを掛けて加える。同じ数字列でも基数が変われば値は変わる。

QUESTION 228#center_style_original_202608_0013

4ビットの符号なし2進数1111に1を加え、5桁目への桁上がりは捨てる。得られる4ビットの値を次から選べ。

  1. 0

    1110

  2. 1

    0001

  3. 2

    1000

  4. 3

    0000

正答と解説を確認

正答3. 0000

解説

4ビットで表せる符号なし整数は0から15までである。1111に1を加えると10000になるが、5桁目を保存できないため、下位4ビットの0000だけが残る。限られたビット数では、最大値を超えると値が一周したように戻ることがある。

QUESTION 229#center_style_original_202608_0014

1バイトを上位4ビットと下位4ビットに分け、上位を16進数B、下位を16進数3で表した。バイト全体の2進表現を次から選べ。

  1. 0

    10111000

  2. 1

    10110011

  3. 2

    10100011

  4. 3

正答1. 10110011

16進数1桁は2進数4ビットに対応する。上位と下位の順序を保ち、各16進数字を4ビットずつへ直す。

QUESTION 230#center_style_original_202608_0015

8ビットの値10001111とマスク11110000の各ビットについてAND演算を行った結果を次から選べ。

  1. 0

    11111111

  2. 1

    10000000

  3. 2

    01111111

  4. 3

    10001111

正答と解説を確認

正答1. 10000000

解説

ANDとマスクを使うと、マスクが1の位置だけ元のビットを残し、0の位置を消せる。必要なビット範囲の取り出しに利用される。
