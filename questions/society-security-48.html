QUESTION 471#center_style_original_202608_0387

同じ演奏会について、主催者の広告、新聞評、来場者の口コミで評価が異なっていた。メディアリテラシーを働かせた読み方を次から選べ。

  1. 0

    各媒体の目的・発信者・根拠を確認し、事実の記述と評価意見を分けて比較する

  2. 1

    広告は画像が鮮明なので、主催者の利害関係を考えず最も客観的だと判断する

  3. 2

    口コミは個人の感想なので、数が一件でも全来場者の総意だとみなす

  4. 3

    媒体間で内容が一致しない場合は、比較せず全資料を虚偽として扱う

正答と解説を確認

正答0. 各媒体の目的・発信者・根拠を確認し、事実の記述と評価意見を分けて比較する

解説

媒体ごとの制作目的と立場、証拠の質を確認し、検証可能な事実と主観的評価を区別すると違いを適切に理解可能になる。画質は主張の正確さを保証しない。販売促進を目的とする発信者の立場も考慮する必要になる。

QUESTION 472#center_style_original_202608_0388

ある記事に「市の人口は前年から20％増えた」とある。市の統計表では、同じ定義・同じ時点の人口が前年50,000人、今年52,000人だった。この主張を評価したものとして最も適当なものを次から選べ。

  1. 0

    統計表から増加率は4％と計算できるため、記事の20％という主張はこの資料では裏付けられない

  2. 1

    人口は2,000人増えているため、増加率を確認しなくても記事の20％という主張を採用できる

  3. 2

    市が公開した表は一次資料なので、記事に示された20％という数値も同じ資料から得たと判断できる

  4. 3

    記事と統計表で数値が異なるため、どちらも信頼できない資料として検討の対象から外す

正答と解説を確認

正答0. 統計表から増加率は4％と計算できるため、記事の20％という主張はこの資料では裏付けられない

解説

信ぴょう性の確認では、発信者の肩書だけでなく、主張を一次資料の数値から再計算できるかを見る。割合は「変化量÷変化前の値」で求め、資料間で対象・時点・単位が同じかも確認する。

QUESTION 473#center_style_original_202608_0391

送信者のデジタル署名の検証には成功したが、文書本文は暗号化されておらず誰でも読める状態だった。この事例から分かるデジタル署名の性質を次から選べ。

  1. 0

    完全性や署名者の真正性の確認には役立つが、文書内容の機密性を自動的には与えない

  2. 1

    署名検証に成功した文書は暗号化済みなので、第三者には内容を読まれない

  3. 2

    署名後に本文が変更されても、署名が元の内容へ自動的に修復する

  4. 3

    署名検証に成功すれば、文書に書かれた事実の正しさまで保証される

正答と解説を確認

正答0. 完全性や署名者の真正性の確認には役立つが、文書内容の機密性を自動的には与えない

解説

デジタル署名で確認するのは、署名後に内容が変わっていないことと、署名に使った鍵が誰に対応するかである。秘密に読む機密性、内容の真実性、改ざん後の自動修復は別の性質であり、暗号化や事実確認、バックアップなどが必要になる。

QUESTION 474#center_style_original_202608_0392

送信元・宛先IPアドレスやポート番号を規則と照合する一般的なパケットフィルタリング型ファイアウォールについて、この機能だけでは通常判断できないものを次から選べ。

  1. 0

    通信方向を問わず、登録した送信元IPアドレスから来る受信パケットを拒否する

  2. 1

    接続状態や本文を参照せず、宛先ポート番号22への受信パケットを拒否する

  3. 2

    個別の許可規則に一致しない受信パケットを、既定の処理として拒否する

  4. 3

    復号を行わずに、HTTPSで暗号化された本文中の入力内容が安全かを判定する

正答と解説を確認

正答3. 復号を行わずに、HTTPSで暗号化された本文中の入力内容が安全かを判定する

解説

パケットフィルタは、主に通信の送信元・宛先、ポート番号、方向などを見て通過を制御する。HTTPSの本文は暗号化されているため、ヘッダの規則だけでは利用者が偽サイトへ入力した内容などを判断できない。端末対策、認証、利用者教育などを重ねる必要がある。

QUESTION 475#center_style_original_202608_0393

本人の身体的特徴を用いる生体認証の組合せを次から選べ。

  1. 0

    暗証番号とパスワード

  2. 1

    生年月日と住所

  3. 2

    指紋と虹彩

  4. 3

    社員番号とメールアドレス

正答と解説を確認

正答2. 指紋と虹彩

解説

指紋の隆線パターンと虹彩の模様は個人差のある身体的特徴で、生体認証に利用される。暗証番号とパスワードは本人が記憶して提示する知識要素で、身体的特徴とはいえない。

QUESTION 476#center_style_original_202608_0397

機密性のある大容量研究データを、組織外の共同研究者一人と一定期間だけ共有したい。共有方法として最も適当なものを次から選べ。

  1. 0

    認証付き共有領域で相手と期限・権限を限定し、別経路で通知してアクセス記録を確認する

  2. 1

    大容量データを誰でも閲覧できるURLへ置き、共同研究者が検索しやすいよう検索エンジンにも登録する

  3. 2

    共同研究者のアカウントや本人性を確認せず、公開SNSの複数投稿へ研究データを分割して掲載する

  4. 3

    データを暗号化せず組織の全員宛てメールへ分割添付し、複数回に分けて容量制限を回避する

正答と解説を確認

正答0. 認証付き共有領域で相手と期限・権限を限定し、別経路で通知してアクセス記録を確認する

解説

安全な共有では、相手の本人確認、必要最小限の権限、有効期限、アクセス記録を組み合わせる。大容量かどうかは送付手段の選択に関わるが、機密性は容量ではなく、誰がいつまで取得できるかを制御できるかで判断する。

QUESTION 477#center_style_original_202608_0403

コールセンター通話を音声認識で文字化し、要望カテゴリを自動分類して業務改善に使う。分析結果を利用する前に確認すべき事項の組合せを次から選べ。

  1. 0

    認識精度が高いサービスなら誤変換は無視できるため、原音との照合を省く

  2. 1

    音声認識誤り、分類精度、個人情報の保護、当初示した利用目的との整合

  3. 2

    同じ利用者の履歴を追えるよう、氏名などの個人情報は目的や期限を定めず全て保存する

  4. 3

    文字化と分類の精度が十分高ければ、利用目的の説明やアクセス権の確認は省いてよい

正答と解説を確認

正答1. 音声認識誤り、分類精度、個人情報の保護、当初示した利用目的との整合

解説

自動分析では、結果の品質とデータの取扱いを別々に点検する。品質面では原音との照合やカテゴリ別の誤り、取扱い面では利用目的、必要最小限の情報、保存期間、アクセス権を確認する。精度が高くてもプライバシー上の問題は消えない。

QUESTION 478#center_style_original_202608_0407

職員に「情報システム担当です。障害対応のため、今届いた認証コードを教えてください」という電話があった。組織の対策として最も適当なものを次から選べ。

  1. 0

    発信者番号が社内番号に見える場合は担当者とみなし、障害対応を優先して認証コードを伝える手順にする

  2. 1

    認証情報を電話で伝えない規則を定め、登録済みの連絡先へ折り返して確認し、事例を報告・共有する

  3. 2

    担当部署からの電話に備え、部署内で共通の認証情報を用意して問い合わせへの回答を統一する

  4. 3

    不審電話を受けた職員だけへ個別に注意し、同じ手口を他の職員へ知らせず通常業務を続ける

正答と解説を確認

正答1. 認証情報を電話で伝えない規則を定め、登録済みの連絡先へ折り返して確認し、事例を報告・共有する

解説

人の信頼や緊急性につけ込んで秘密を聞き出す手口を、ソーシャルエンジニアリングという。通信機器だけでは防げないため、確認手順・教育・報告しやすい窓口を整える。

QUESTION 479#center_style_original_202608_0408

フィッシングによる認証情報の悪用被害を減らすために、避けるべき行動を次から選べ。

  1. 0

    十分に長い一つのパスワードを、複数のサービスで共通して使う

  2. 1

    メールやSMSのリンクを不用意に開かず、公式アプリやブックマークから接続する

  3. 2

    迷惑メッセージのフィルタやブロック機能を活用する

  4. 3

    OS、ブラウザ、アプリを正規の手段で最新状態に保つ

正答と解説を確認

正答0. 十分に長い一つのパスワードを、複数のサービスで共通して使う

解説

パスワードを使い回すと、一つのサービスから漏れた組合せを別サービスへ試す攻撃が成功しやすい。サービスごとに異なる長いパスワードを使い、多要素認証も併用する。公式経路からのアクセスや更新は、フィッシングの入口を減らす対策になる。

QUESTION 480#center_style_original_202608_0409

クレジットカードの磁気情報の盗取りや、その情報を使った不正利用による被害を減らす行動として不適切なものを次から選べ。

  1. 0

    ICチップ対応の取引を利用し、磁気ストライプ情報だけに依存する取引を避ける

  2. 1

    利用通知を有効にし、明細を定期的に確認して身に覚えのない取引を早く届け出る

  3. 2

    暗証番号の入力時に手元を覆い、カードから目を離さない

  4. 3

    カード会社を名乗るメールのリンクから、カード番号と暗証番号を直ちに再登録する

正答と解説を確認

正答3. カード会社を名乗るメールのリンクから、カード番号と暗証番号を直ちに再登録する

解説

メールやSMSで急かされても、そのリンクからカード情報や暗証番号を入力しない。公式アプリやカード裏面の連絡先など、メッセージとは独立した経路で確認する。
