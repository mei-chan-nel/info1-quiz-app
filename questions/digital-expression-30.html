QUESTION 291#center_style_original_202608_0204

ある色成分について0を含む1,024段階を互いに異なる固定長のビット列で表したい。必要な最小ビット数を次から選べ。

  1. 0

    8ビット

  2. 1

    9ビット

  3. 2

    12ビット

  4. 3

    10ビット

正答と解説を確認

正答3. 10ビット

解説

固定長nビットで表せる種類数は2ⁿである。必要なビット数は、種類数以上になる最小の2の指数を探して決める。

QUESTION 292#center_style_original_202608_0205

RGBの各成分を8ビットから10ビットへ増やし、各成分の値を独立に組み合わせる。1画素で表現できる色数が何倍になるかを次から選べ。

  1. 0

    4倍

  2. 1

    8倍

  3. 2

    16倍

  4. 3

    64倍

正答と解説を確認

正答3. 64倍

解説

各成分を8から10ビットへ増やすと段階数は2²＝4倍になる。独立な3成分の組合せは4³＝64倍で、ビット数の比10/8とは異なる。

QUESTION 294#center_style_original_202608_0218

利用者の頭や体の動きに応じて、コンピュータが生成した三次元空間内の視点が変化するVRの利用例に該当しないものを次から選べ。

  1. 0

    仮想火災現場で頭を動かして周囲を見回し、表示される三次元空間の中から避難経路を選ぶ訓練をする

  2. 1

    仮想住宅内で体や頭を動かすと視点も連動して移動し、部屋の広さや間取りを任意の方向から確認する

  3. 2

    三次元の仮想人体を頭や手の動きに合わせて回転・拡大し、任意の方向から観察して手術手順を練習する

  4. 3

    固定カメラで撮影済みの道路映像を、頭の動きとは無関係に通常の2D画面で再生する

正答と解説を確認

正答3. 固定カメラで撮影済みの道路映像を、頭の動きとは無関係に通常の2D画面で再生する

解説

VRは、コンピュータが作る空間へ利用者の動きや操作を反映し、視点を変えながら体験できる点が重要である。通常の2D動画は映像を再生するだけで、頭の動きに応じて仮想空間の視点を計算し直さない。

QUESTION 295#center_style_original_202608_0219

一本の動画を、冒頭2分は24 fps、続く30秒は60 fpsで構成し、それぞれの区間では一定のフレームレートとした。動画全体を構成するフレーム数を次から選べ。

  1. 0

    3,600枚

  2. 1

    2,940枚

  3. 2

    4,680枚

  4. 3

    9,000枚

正答と解説を確認

正答2. 4,680枚

解説

フレームレートが区間によって異なるため、各区間のフレーム数を別々に求める。前半2分は120秒なので120×24＝2,880枚、後半30秒は30×60＝1,800枚である。合計は2,880＋1,800＝4,680枚となる。

QUESTION 296#center_style_original_202608_0220

QUESTION 297#center_style_original_202608_0221

2進数で実数の大きさを表す一般的な浮動小数点表現には、正負を示す符号部、桁の位置を調整する指数部、有効数字を保持する仮数部がある。三つの役割の組合せとして最も適当なものを次から選べ。

  1. 0

    符号部は指数の正負、指数部は有効数字、仮数部は数全体の正負を表す

  2. 1

    符号部は正負、指数部は値の尺度、仮数部は有効数字を表す

  3. 2

    符号部は正負、指数部は小数点以下の桁数だけ、仮数部は単位を表す

  4. 3

    符号部は誤り検出、指数部は桁上がり、仮数部はアドレスを表す

正答と解説を確認

正答1. 符号部は正負、指数部は値の尺度、仮数部は有効数字を表す

解説

浮動小数点数は、符号・有効数字・小数点を動かす尺度に分けて考える。符号部が正負、仮数部が有効数字、指数部が値の大きさの桁を調整する。限られたビット数で表すため、実数によっては丸め誤差が生じる。

QUESTION 298#center_style_original_202608_0226

一台のコンピュータで複数のアプリケーションを並行して動作させるとき、オペレーティングシステム（OS）が担う役割として最も適当なものを次から選べ。

  1. 0

    最初に起動したアプリケーションへCPUと主記憶を固定し、他の処理には割り当てない

  2. 1

    各アプリケーション自身に他プロセスのメモリを自由に上書きさせ、OSは仲介しない

  3. 2

    全プロセスを同時に一命令ずつ物理的に実行できるよう、単一CPUを自動的に複製する

  4. 3

QUESTION 299#center_style_original_202608_0228

一般的な加法混色でRGB各成分を0.0～1.0の強度で表す。画素値を(0.0, 0.0, 0.0)から(1.0, 1.0, 1.0)へ連続的に変化させたときの見え方を次から選べ。

  1. 0

    黒から無彩色のまま明るくなり、最後は白になる

  2. 1

    赤だけが強くなり、最後は純粋な赤になる

  3. 2

    白から無彩色のまま暗くなり、最後は黒になる

  4. 3

    三成分が同時に変化するので、明るさも色も変化しない

正答と解説を確認

正答0. 黒から無彩色のまま明るくなり、最後は白になる

解説

加法混色では光を加えるほど明るくなる。RGB三成分が等しければ黒から灰色を経て白へ進み、成分間に差があると色味が生じる。RGBが全て0なら黒、全て最大なら白という両端を基準に考える。

QUESTION 300#center_style_original_202608_0229

RGB各成分を3ビット、すなわち8階調で表すカラー画像がある。行ごとのパディングや付加情報を設けず、画素データをビット単位で隙間なく格納するとき、16画素分のデータ量を次から選べ。

  1. 0

    6バイト

  2. 1

    16バイト

  3. 2

    48バイト

  4. 3

    18バイト

正答と解説を確認

正答3. 18バイト

解説

1画素のビット数は各成分のビット数を足して求める。合計ビット数が8の倍数なら、8で割って端数なくバイトへ換算できる。
