QUESTION 181#center_style_original_202608_0331

ルータが受け取ったIPパケットを次のネットワークへ転送するとき、転送先を決めるために主に参照する情報を次から選べ。

  1. 0

    電子メールの送信者名

  2. 1

    送信ファイルの拡張子

  3. 2

    Webページに付けられたタイトル

  4. 3

    宛先IPアドレス

正答と解説を確認

正答3. 宛先IPアドレス

解説

IPパケットには送信元と宛先のIPアドレスが含まれる。ルータは宛先IPアドレスを経路情報と照合し、パケットを次のネットワークへ送る。メールの送信者名やファイルの種類など、通信内容の意味から経路を選ぶわけではない。

QUESTION 182#center_style_original_202608_0385

家庭Aと家庭Bの端末に、どちらもプライベートIPv4アドレス192.168.1.10が設定されている。各家庭の端末がWebサイトへ接続できる理由を説明したものとして最も適当なものを次から選べ。

  1. 0

    DNSが端末ごとに異なるプライベートIPv4アドレスへ書き換えるため、同じ番号でも重複しない

  2. 1

    Webサーバが家庭内の端末へ直接プライベートIPv4アドレスを割り当て直すため、通信を区別できる

  3. 2

    プライベートIPv4アドレスは家庭ごとに再利用でき、各家庭のルータが外部との通信を対応付けて中継する

  4. 3

    IPv4アドレスは端末名から毎回自動生成されるため、画面上で同じ番号でも内部では異なる番号になる

正答と解説を確認

正答2. プライベートIPv4アドレスは家庭ごとに再利用でき、各家庭のルータが外部との通信を対応付けて中継する

解説

プライベートIPv4アドレスはインターネット全体で一意ではなく、家庭や組織の内部で使う。DNSの名前解決、DHCPによる端末設定、ルータによるネットワーク間の中継を区別すると、役割を混同しにくい。

QUESTION 183#center_style_original_202608_0394

メールアドレス「taro@example.ed.jp」を、@の前後で分けた構成の説明を次から選べ。

  1. 0

    taroがローカル部、example.ed.jpがドメイン部である

  2. 1

    taroがドメイン部、example.ed.jpがローカル部である

  3. 2

    taro@exampleがローカル部、ed.jpだけがドメイン部である

  4. 3

    @を含む文字列全体がローカル部で、ドメイン部は省略されている

正答と解説を確認

正答0. taroがローカル部、example.ed.jpがドメイン部である

解説

メールアドレスは@を境に、前が利用者やメールボックスを表すローカル部、後ろが配送先の組織・サーバ側を表すドメイン部になる。ドメイン部に複数の点があっても、@より後ろ全体を一つのドメイン名として読む。

QUESTION 184#center_style_original_202608_0396

一般的な電子メールで、送信者がメールソフトから送信し、受信者が自分のメールソフトで受け取るまでの主な流れを次から選べ。

  1. 0

    受信者のメールソフト→送信側メールサーバ→送信者のメールソフト

  2. 1

    送信者のメールソフト→送信側メールサーバ→受信側メールサーバ→受信者のメールソフト

  3. 2

    送信側メールサーバ→受信者のメールソフト→送信者の端末

  4. 3

    送信者のメールソフト→受信者のメールソフト→DNSだけ→受信側メールサーバ

正答と解説を確認

正答1. 送信者のメールソフト→送信側メールサーバ→受信側メールサーバ→受信者のメールソフト

解説

送信者のクライアントは送信サーバへ預け、サーバ間で配送し、受信者は受信サーバ上のメールをIMAP等で閲覧・取得するといえる。情報の流れが受信者から送信者へ逆向きになっており、送信者のメールも受信側サーバを経ていない。

QUESTION 185#center_style_original_202608_0425

大学の各キャンパス内では建物内のLANを構築し、遠隔地にある二つのキャンパスのLAN同士を通信事業者の広域回線で接続した。ネットワーク分類の組合せを次から選べ。

  1. 0

    各キャンパス内はWAN、キャンパス間はLAN

  2. 1

    各キャンパス内はPAN、キャンパス間もPAN

  3. 2

    各キャンパス内はWAN、キャンパス間もWAN

  4. 3

    各キャンパス内はLAN、キャンパス間はWAN

正答と解説を確認

正答3. 各キャンパス内はLAN、キャンパス間はWAN

解説

限定された各拠点内をLAN、離れたLAN同士を結ぶ広域回線をWANと分類する。建物・敷地内の限定範囲がLAN、遠隔地間の広域接続がWANなので逆である。

QUESTION 186#center_style_original_202608_0433

送信者Wが、宛先ToにX、CCにY、BCCにZの各メールアドレスを指定して送信した。Yが受信メールの通常のヘッダ表示で確認できる送信者・To・CCの組合せを次から選べ。

  1. 0

    W・X・Y・Z

  2. 1

    W・X・Y

  3. 2

    W・Y・Z

  4. 3

    W・X・Z

正答と解説を確認

正答1. W・X・Y

解説

FromにはW、ToにはX、CCにはYが表示される。BCCのZは他の受信者へ伏せるため通常の受信ヘッダには表示されない。ZはBCC受信者であり、Yに見えるTo・CC欄へZを含めるとBCCの秘匿目的に反する。
