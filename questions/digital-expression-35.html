QUESTION 341#center_style_original_202608_0327

CPUを構成する制御装置と演算装置の役割の組合せとして最も適当なものを次から選べ。

  1. 0

    制御装置は命令を解読して各部へ指示し、演算装置は算術演算や論理演算を行う

  2. 1

    制御装置は数値計算だけを行い、演算装置は命令の取出し順序だけを管理する

  3. 2

    制御装置はファイルを長期保存し、演算装置はキーボードから文字を入力する

  4. 3

    制御装置と演算装置はいずれも主記憶装置の別名で、役割の違いはない

正答と解説を確認

正答0. 制御装置は命令を解読して各部へ指示し、演算装置は算術演算や論理演算を行う

解説

制御装置は命令を解読し、演算装置や記憶装置などへ処理の指示を出す。演算装置は、その指示に従って加減算や論理演算を行う。処理を指示する役割と、実際に計算する役割を区別する。

QUESTION 342#center_style_original_202608_0328

補助記憶装置に保存されているプログラムを実行するとき、OSがプログラムの命令や必要なデータを主記憶へ読み込む主な理由を次から選べ。

  1. 0

    CPUが実行中に命令やデータへ高速にアクセスできるようにする

  2. 1

    主記憶は補助記憶より低速だが、電源を切っても内容を保持できる

  3. 2

    補助記憶上の命令はCPUが直接解読できるため、主記憶へ移す必要は本来ない

  4. 3

    主記憶へ読み込むとプログラムが自動的に機械語から高級言語へ戻るため

正答と解説を確認

正答0. CPUが実行中に命令やデータへ高速にアクセスできるようにする

解説

主記憶は補助記憶より高速だが、電源を切ると内容を失う揮発性の記憶である。保存は補助記憶、実行中の高速な読み書きは主記憶という役割分担をする。

QUESTION 343#center_style_original_202608_0329

複数のアプリケーションを同時に動かすとき、OSが主記憶を管理する目的として最も適当なものを次から選べ。

  1. 0

    各アプリケーションへ必要な領域を割り当て、互いのデータを不用意に書き換えにくくする

  2. 1

    全アプリケーションに同じ領域だけを割り当て、同じデータを同時に上書きさせる

  3. 2

    主記憶の内容を全て画面へ表示し、利用者が手作業で割当てを決める

  4. 3

    アプリケーションのファイルを全て削除し、主記憶を常に空の状態へ戻す

正答と解説を確認

正答0. 各アプリケーションへ必要な領域を割り当て、互いのデータを不用意に書き換えにくくする

解説

OSは、実行中のプログラムへ主記憶の領域を割り当て、使用後に回収する。各プログラムの領域を適切に分けることで、互いのデータへの不用意な干渉を防ぎ、限られた主記憶を効率よく利用する。

QUESTION 344#center_style_original_202608_0332

アナログ音声をPCMのビット列へ変換する標本化、量子化、符号化の役割の組合せを次から選べ。

  1. 0

    量子化で振幅を丸め、標本化で測定時刻を後から選び、符号化でビット列にする

  2. 1

    標本化で段階値をビット列にし、量子化で時刻を選び、符号化で振幅を丸める

  3. 2

    標本化―時間軸上で値を取り出す、量子化―振幅を段階値へ対応させる、符号化―段階値をビット列で表す

  4. 3

    標本化と量子化だけでビット列が完成し、符号化はアナログ音声へ戻した後に行う

正答と解説を確認

正答2. 標本化―時間軸上で値を取り出す、量子化―振幅を段階値へ対応させる、符号化―段階値をビット列で表す

解説

時間の離散化、振幅の離散化、数値のビット列化を正しく対応させているといえる。連続信号から時刻ごとの標本を得た後に、その振幅を量子化するため順序が逆である。

QUESTION 345#center_style_original_202608_0333

配布用ソフトウェアの更新ファイルを圧縮し、展開後のハッシュ値が配布元の元ファイルと完全に一致する必要がある。用いるべき圧縮方式の性質を次から選べ。

  1. 0

    展開時に元の全ビットを復元できる可逆圧縮

  2. 1

    人が気付きにくい命令を削除する非可逆圧縮

  3. 2

    展開時に欠けたバイトを類似ファイルから推測する方式

  4. 3

    実行ファイルを画像向けの非可逆圧縮で近似保存する方式

正答と解説を確認

正答0. 展開時に元の全ビットを復元できる可逆圧縮

解説

ハッシュ値は入力のビット列が少し変わっても通常は変化する。プログラムや文書など元のビット列が必要なデータには可逆圧縮を使い、非可逆圧縮と区別する。

QUESTION 346#center_style_original_202608_0338

互いに独立な25個のセルからなる二次元コードを考え、各セルは白または黒の2値を取れるものとする。セル配置の制約や予約領域がない場合、表現できる全パターン数を次から選べ。

  1. 0

    25通り

  2. 1

    2²⁵通り

  3. 2

    50通り

  4. 3

    25²通り

正答と解説を確認

正答1. 2²⁵通り

解説

独立な選択を組み合わせるときは積の法則を使う。各セルが2通りで25個あるため2²⁵通りとなる。実際の二次元コードでは位置検出用などの固定領域や規則があり、全セルを自由に使えるとは限らない。

  2. 1

    2ビット

  3. 2

    3ビット

  4. 3

8種類を固定長で区別するには2³＝8より3ビット必要である。一般には2ⁿが種類数以上となる最小のnを選ぶ。

QUESTION 348#center_style_original_202608_0340

互いに異なるn個の作品があり、各作品について展示に選ぶか選ばないかを独立に決める。何も選ばない場合も含む選び方の総数を次から選べ。

  1. 0

    n通り

  2. 1

    2n通り

  3. 2

    n²通り

  4. 3

    2ⁿ通り

正答と解説を確認

正答3. 2ⁿ通り

解説

各対象を選ぶ・選ばないの2通りと考えると、n個で2ⁿ通りになる。何も選ばない場合を除くなら1を引いて2ⁿ−1通りである。

QUESTION 349#center_style_original_202608_0350

文化祭の写真データを複数の生徒が同じファイル形式のまま保存し、さらにSNSで共有した。デジタル情報の性質を踏まえた説明として最も適当なものを次から選べ。

  1. 0

    別の端末へ保存すると元の端末から写真が移動するため、同じ写真を複数人が持つことはできない

  2. 1

    共有の回数が増えるたびにビット列の一部が失われるため、同じファイルを保ったまま伝えることはできない

  3. 2

    最初の投稿を削除すれば、受信者の保存や再投稿も元の投稿と連動して削除される

  4. 3

    同じビット列を複数の端末へ複製しやすく、共有によって短時間に広い範囲へ伝わる可能性がある

正答と解説を確認

正答3. 同じビット列を複数の端末へ複製しやすく、共有によって短時間に広い範囲へ伝わる可能性がある

解説

「複製」「移動」「削除」を区別する。複製では元データが残り、削除が及ぶのは通常その保存場所だけである。受信者が作った複製まで後から制御できるとは限らない。

QUESTION 350#center_style_original_202608_0365

磁気ディスクを用いるハードディスクドライブ（HDD）がビット0と1を記録する基本的な仕組みを次から選べ。

  1. 0

    フラッシュメモリセルの電荷状態として記録する

  2. 1

    光ディスク表面のピットとランドとして記録する

  3. 2

    揮発性メモリセルの電荷を通電中だけ保持する

  4. 3

    ディスク表面の磁性体の磁化状態の違いとして記録する

正答と解説を確認

正答3. ディスク表面の磁性体の磁化状態の違いとして記録する

解説

回転ディスク上の磁性体の磁化状態を読み書きし、ビットを不揮発に保存する。電荷をフラッシュメモリセルへ保持するのはSSD等の仕組みで、磁気ディスクとはいえない。
