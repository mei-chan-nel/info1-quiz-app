QUESTION 131#center_style_original_202608_0211

二つの量的変数について計算したピアソンの相関係数に関する説明として最も適当なものを次から選べ。

  1. 0

    相関係数が0に近ければ、二つの変数には曲線的な関係もないと判断できる

  2. 1

    1に近いほど強い正の線形関係、−1に近いほど強い負の線形関係を示す

  3. 2

    負の値は相関がないことを示し、絶対値の大きさには意味がない

  4. 3

    絶対値が大きければ、相関係数だけで一方が他方の原因だと証明できる

正答と解説を確認

正答1. 1に近いほど強い正の線形関係、−1に近いほど強い負の線形関係を示す

解説

ピアソンの相関係数は−1から1の範囲をとり、符号が線形関係の向き、絶対値が線形関係の強さを示す。相関係数0は線形関係が弱いことを示すが、曲線的な関係など非線形の関係が存在する可能性は残るといえる。

QUESTION 132#center_style_original_202608_0212

国内の高校生全体の1か月の小遣い額を推定するために標本調査を行う。標本の選び方として最も適当なものを次から選べ。

  1. 0

    回答を集めやすい一つの高校の友人だけを対象にする

  2. 1

    小遣いに関心のある人だけが自由に回答するWebアンケートにする

  3. 2

    小遣い額が平均に近そうな生徒を調査者の判断で選ぶ

  4. 3

    地域や学年など母集団の構成を考慮した上で、対象者を無作為に抽出する

正答と解説を確認

正答3. 地域や学年など母集団の構成を考慮した上で、対象者を無作為に抽出する

解説

母集団の構成を反映するよう層などを設計し、各対象を無作為に選べば、選択バイアスを抑えて推定しやすいといえる。一つの学校と友人に限る便宜抽出では、地域・学校・交友関係などの偏りが生じ、全国の高校生へ一般化しにくい。

QUESTION 133#center_style_original_202608_0213

ある地域の住宅価格10件のうち9件は2,000万～3,000万円、1件だけが2億円であった。この10件の典型的な価格を一つの代表値で示すとき、平均値より中央値を検討する理由として最も適当なものを次から選べ。

  1. 0

    平均値はデータが10件以上あると定義できず、中央値だけが計算できる

  2. 1

    中央値は全ての観測値を加算して件数で割るので、外れ値を自動的に削除できる

  3. 2

    平均値は極端に大きい1件の影響を強く受けるが、中央値はその影響を受けにくい

  4. 3

    外れ値は代表値をゆがめるため、理由を調べる前に集計対象から外す

正答と解説を確認

正答2. 平均値は極端に大きい1件の影響を強く受けるが、中央値はその影響を受けにくい

解説

平均値は2億円を加算に含めるため大きく押し上げられるが、順位の中央で決まる中央値は一つの極端な値の影響を受けにくい。平均値は件数が10件でも計算できる。問題は計算可能性ではなく、外れ値によって代表性が損なわれる場合があることだ。

QUESTION 134#center_style_original_202608_0215

摂氏温度（℃）の尺度水準を次から選べ。

  1. 0

    名義尺度

  2. 1

    間隔尺度

  3. 2

    比例尺度

  4. 3

    順序尺度

正答と解説を確認

正答1. 間隔尺度

解説

摂氏温度は1℃の間隔がどの位置でも等しく、温度差には意味があるが、0℃は温度が存在しないことを示す絶対的な0ではないため、間隔尺度である。名義尺度は分類のための名称や番号を表し、値の大小や差に数量的な意味をもたない。摂氏温度では温度差を比較可能になる。

QUESTION 135#center_style_original_202608_0216

身長（cm）の尺度水準を次から選べ。

  1. 0

    名義尺度

  2. 1

    間隔尺度

  3. 2

    比例尺度

  4. 3

    順序尺度

正答と解説を確認

正答2. 比例尺度

解説

尺度水準は、分類、順序、差、比のどこまで意味があるかで判断する。身長は大小と差を扱え、0cmが長さのない状態なので比にも意味がある。絶対的な0があるかを確認すると、間隔尺度と比例尺度を区別しやすい。

QUESTION 136#center_style_original_202608_0217

複数の地域で「気温が高い日ほど飲料の販売数が多い」という個別の観察結果を得て、気温と販売数に一般的な傾向があるという仮説を立てた。この推論の種類を次から選べ。

  1. 0

    一般法則と条件から個別の結論を必然的に導く演繹的推論

  2. 1

    複数の個別観察から一般的な傾向を仮説化する帰納的推論

  3. 2

    観察結果を最もよく説明しそうな原因を仮説として選ぶ仮説推論

  4. 3

    別のよく似た事例との共通点から性質を推測する類推

正答と解説を確認

正答1. 複数の個別観察から一般的な傾向を仮説化する帰納的推論

解説

複数地域の具体的観察から一般的傾向を立てるため、帰納に当たる。問題は一般法則を前提に個別結論を出すのではなく、観察から一般化している。

QUESTION 137#center_style_original_202608_0240

自由記述アンケートを多数集め、頻出語だけでなく「授業」と「難しい」のように同じ回答内で共に現れやすい語の関係も分析したい。最も適した方法を次から選べ。

  1. 0

    各回答の文字数だけを数え、単語へ分割せず内容を分析しない

  2. 1

    テキストマイニングで語の頻度と共起関係を抽出する

  3. 2

    語の出現回数だけを集計し、どの語が同じ回答内に現れたかは記録しない

  4. 3

    各回答を一つの評価カテゴリへ分類するだけで、本文から語を抽出しない

正答と解説を確認

正答1. テキストマイニングで語の頻度と共起関係を抽出する

解説

共起とは、二つの語が同じ文や回答内に一緒に現れる関係である。頻度だけでは見えない話題の結び付きを調べられるが、共起だけで因果関係があるとはいえない。

QUESTION 138#center_style_original_202608_0254

地域騒音を調べる学生にとって、自ら現地で測定・記録した未加工の値を一次情報、他者が収集して整理・公表した資料を二次情報と定義する。この定義に合う組合せを次から選べ。

  1. 0

    自治体の集計報告書が一次情報、学生自身の騒音測定値が二次情報

  2. 1

    学生自身の騒音測定値が一次情報、自治体が既存測定を集計した報告書が二次情報

  3. 2

    検索サービスが作った要約が一次情報、要約の基になった測定記録が二次情報

  4. 3

    自分で測定した値も自治体の集計報告書も、利用者にとって同じ一次情報に当たる

正答と解説を確認

正答1. 学生自身の騒音測定値が一次情報、自治体が既存測定を集計した報告書が二次情報

解説

一次・二次の区別は、情報の内容だけでなく、誰がどの目的で直接取得したかを見る。この問題の定義では、学生自身の測定値は一次情報、他者が収集・整理した報告書は二次情報である。二次情報を使うときは元データや集計方法も確認する。

QUESTION 139#center_style_original_202608_0261

順に並ぶ三つの階級の相対度数が0.20、0.50、0.30である。第2階級までの累積相対度数を次から選べ。

  1. 0

    0.2

  2. 1

    0.3

  3. 2

    0.7

  4. 3

    0.5

正答と解説を確認

正答2. 0.7

解説

累積相対度数は、最初の階級から指定された階級までの相対度数を加える。第2階級までなら0.20＋0.50＝0.70である。最後の階級まで加えれば、丸め誤差を除いて1になる。

QUESTION 140#center_style_original_202608_0266

学習時間と確認テスト得点の散布図を作ると、点は右上がりに分布し、相関係数は0.85であった。この結果から直接いえることとして最も適当なものを次から選べ。

  1. 0

    学習時間を増やせば、ほかの条件に関係なく得点が必ず上がる

  2. 1

    学習時間と得点には、ほとんど関係が見られない

  3. 2

    全ての点が一本の直線上に並ぶ完全な正の相関である

  4. 3

    学習時間が長い人ほど得点が高い傾向はあるが、この結果だけでは因果関係は断定できない

正答と解説を確認

正答3. 学習時間が長い人ほど得点が高い傾向はあるが、この結果だけでは因果関係は断定できない

解説

相関係数は−1から1の範囲をとり、1に近いほど強い正の直線的な関係を示す。ただし、相関は二つの変数が一緒に変化する傾向を示すもので、片方がもう片方の原因だと証明するものではない。散布図も併せて外れ値や分布を確認する。
