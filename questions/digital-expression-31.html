QUESTION 301#center_style_original_202608_0230

RGB各成分の階調数をそれぞれ元の2倍にし、各成分の値を独立に組み合わせる。1画素で表現できる色数が元の何倍になるかを次から選べ。

  1. 0

    2倍

  2. 1

    4倍

  3. 2

    8倍

  4. 3

    6倍

正答と解説を確認

正答2. 8倍

解説

独立に選べる要素の組合せ数は、それぞれの選択肢数を掛ける。R・G・Bが各2倍なら全体は2×2×2＝8倍になる。成分数がm個なら、各成分をk倍にしたとき全体はkᵐ倍である。

QUESTION 302#center_style_original_202608_0233

学校がWebサイトでPDF資料を公開し、生徒が各自の端末へダウンロードした。その後、学校が元のPDFをWebサイトから削除した。この状況について最も適当な説明を次から選べ。

  1. 0

    学校が元のPDFを削除すると、ダウンロード済みのPDFも次の接続時に読めなくなる

  2. 1

    ダウンロードはPDFを端末へ移動する処理なので、最初の生徒が保存するとWeb上の元データは消える

  3. 2

    生徒の端末に保存された複製は残り得るため、元のPDFを削除しても回収できたとは限らない

  4. 3

    同じPDFを複数端末へ保存すると端末ごとにビット列が変化し、内容を同一に保てなくなる

正答と解説を確認

正答2. 生徒の端末に保存された複製は残り得るため、元のPDFを削除しても回収できたとは限らない

解説

公開後の削除は、元の掲載場所から見えなくする操作であり、既に作られた複製の回収とは異なる。個人情報などを公開するときは、後から完全には制御できない可能性を考えて事前に確認する。

QUESTION 303#center_style_original_202608_0236

4ビット列1100を、符号なし整数として読んだ値と、最上位ビットを符号、残り3ビットを絶対値とする符号絶対値表現として読んだ値の組合せを次から選べ。

  1. 0

    符号なしでは12、符号絶対値では−4

  2. 1

    符号なしでは12、符号絶対値では−8

  3. 2

    符号なしでは10、符号絶対値では−6

  4. 3

    符号なしでは8、符号絶対値では−4

正答と解説を確認

正答0. 符号なしでは12、符号絶対値では−4

解説

同じビット列でも表現方式が違えば値は変わる。符号なしでは全桁を正の重みで読み、符号絶対値では先頭を符号、残りを絶対値として読む。

QUESTION 304#center_style_original_202608_0237

4ビットの符号なし整数で1101₂を保持している。通常の2進加算で2を加え、桁あふれは生じないものとする。結果の4ビット列を次から選べ。

  1. 0

    1011

  2. 1

    1111

  3. 2

    1100

  4. 3

    1110

正答と解説を確認

正答1. 1111

解説

4ビットの符号なし整数は0～15を表せる。1101₂＝13に2を足すと15で、範囲内なので1111₂となる。計算結果が15を超える場合は5桁目が生じ、4ビットに収めると桁あふれが起こる。

QUESTION 305#center_style_original_202608_0238

4ビットの2の補数表現で1010が表す10進数を次から選べ。

  1. 0

    −10

  2. 1

    −6

  3. 2

    6

  4. 3

    10

正答と解説を確認

正答1. −6

解説

2の補数の負数は、全ビットを反転して1を加えると絶対値が得られる。別法として、最上位を−2ⁿ⁻¹、残りを正の重みとして加えてもよい。

QUESTION 306#center_style_original_202608_0239

5ビットの符号絶対値表現で、最上位ビットを符号、残り4ビットを絶対値とする。この表現方式で値0を表すビット列の組合せを次から選べ。

  1. 0

    00000だけ

  2. 1

    10000だけ

  3. 2

    00000と11111

  4. 3

    00000と10000

正答と解説を確認

正答3. 00000と10000

解説

符号絶対値表現には+0と−0があるため、nビットで表せる異なる整数の個数は2ⁿより1少ない。2の補数表現では0は一通りだけである。

QUESTION 307#center_style_original_202608_0241

SNSで災害現場とされる画像を見つけたが、撮影日時・場所・撮影者が示されていない。再発信する前の検証行動として最も適当なものを次から選べ。

  1. 0

    衝撃の大きさを真実性の根拠として、確認前にできるだけ広く共有する

  2. 1

    逆画像検索で過去の掲載例を探し、自治体等の公的発表や現地情報と照合する

  3. 2

    知人から届いたことだけを根拠に、別の災害で撮られた可能性を除外する

  4. 3

    画像内に説明文が書かれていれば、その文を書いた主体を確認せず事実とみなす

正答と解説を確認

正答1. 逆画像検索で過去の掲載例を探し、自治体等の公的発表や現地情報と照合する

解説

過去の同一画像の有無、信頼できる一次情報、日時・天候・地形など複数の手掛かりを照合すると出所を検証可能になる。感情を強く動かす画像でも、過去画像の転用や加工の可能性がある。確認前の拡散は誤情報による混乱を広げる。

QUESTION 308#center_style_original_202608_0250

倉庫の在庫確認で、RFIDタグと一般的な印刷バーコードを比較する。RFIDの特徴として最も適当なものを次から選べ。

  1. 0

    電波を用いるため、条件によっては見通し線がなくても複数タグを一括して読み取れる

  2. 1

    印刷された模様を光学的に一つずつ撮影する方式だけをRFIDという

  3. 2

    RFIDタグは読取装置と物理的に接触しなければ情報を読み出せない

  4. 3

    RFIDタグに商品情報が入るため、識別子と商品情報を対応付ける管理は不要になる

正答と解説を確認

正答0. 電波を用いるため、条件によっては見通し線がなくても複数タグを一括して読み取れる

解説

RFIDは電波でタグと通信するため、周波数・距離・材質などの条件が合えば、非接触かつ一括で読み取れる。印刷模様をカメラやレーザで読むのはバーコードの特徴であり、RFIDは無線通信を使う。

QUESTION 309#center_style_original_202608_0255

同じ解像度とフレームレートの動画を非可逆圧縮するとき、符号化ビットレートを適切な範囲より大きく下げた場合に起こり得る現象を次から選べ。

  1. 0

    量子化や予測の誤差が減り、元映像より細部が増える

  2. 1

    動きや細部の情報が失われ、ブロック状の乱れなどが目立つ

  3. 2

    解像度とフレームレートが同じなら、ビットレートを下げても画質は変化しない

  4. 3

    ビットレートを下げると、不足分を補うため再生時のフレームレートが上がる

正答と解説を確認

正答1. 動きや細部の情報が失われ、ブロック状の乱れなどが目立つ

解説

符号化できる情報量が不足し、細部や動きを近似し切れず圧縮アーティファクトが生じやすい。使用できるビットを減らしても元にない細部は増えず、一般には量子化誤差が増えるといえる。

QUESTION 310#center_style_original_202608_0256

一定の30 fpsで作られた動画が9,000フレームから成る。再生時間を分単位で表した値を次から選べ。

  1. 0

    3分

  2. 1

    30分

  3. 2

    5分

  4. 3

    50分

正答と解説を確認

正答2. 5分

解説

一定のfpsなら、再生時間（秒）＝総フレーム数÷fpsで求める。9,000÷30＝300秒で、1分＝60秒より300÷60＝5分となる。fpsを掛けるのは時間からフレーム数を求める場合である。
