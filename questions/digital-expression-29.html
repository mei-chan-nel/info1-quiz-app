QUESTION 281#center_style_original_202608_0152

2進符号語の集合 `{0, 10, 110, 111}` の符号語を区切り記号なしで連結して送信しても、左から順に符号語を確定して復号できる理由を次から選べ。

  1. 0

    符号語0は、より長い別の符号語の接頭語になっているから

  2. 1

    すべての符号語に0と1が同じ個数ずつ含まれているから

  3. 2

    長い符号語ほど出現確率が低いと仮定しているから

  4. 3

    どの符号語も、ほかの符号語の接頭語になっていないから

正答と解説を確認

正答3. どの符号語も、ほかの符号語の接頭語になっていないから

解説

符号語の集合 `{0, 10, 110, 111}` では、どの符号語もほかの符号語の接頭語になっていない。このような接頭語自由符号では、符号語を読み終えた時点で次の符号語との区切りを確定できる。

QUESTION 282#center_style_original_202608_0156

R・G・Bの各成分へ同じビット数を割り当て、少なくとも4096色を表したい。透明度は扱わない。各成分の最小ビット数と1画素当たりの合計ビット数の組合せを次から選べ。

  1. 0

    各3ビット、合計9ビット

  2. 1

    各4ビット、合計12ビット

  3. 2

    各5ビット、合計15ビット

  4. 3

    各12ビット、合計36ビット

正答と解説を確認

正答1. 各4ビット、合計12ビット

解説

各成分をbビットで表すRGB画像の色数は(2ᵇ)³＝2³ᵇ色である。4096＝2¹²だから3b≧12を満たす最小の整数はb＝4で、1画素は4×3＝12ビットとなる。

QUESTION 283#center_style_original_202608_0166

有効数字7桁へ丸める10進浮動小数点方式で、1000000に0.1を加えたところ丸め後も1000000になった。この現象を次から選べ。

  1. 0

    アンダーフロー

  2. 1

    オーバーフロー

  3. 2

    情報落ち

  4. 3

    桁落ち

正答と解説を確認

正答2. 情報落ち

解説

大きさが大きく異なる数を限られた桁数で加えると、小さい数の有効な桁が結果に反映されないことがある。この現象を情報落ちという。表現できる最小の0でない値よりも絶対値が小さくなるアンダーフローとは異なる。

QUESTION 284#center_style_original_202608_0171

1フレーム2.25 MBの静止画を毎秒30フレームで6分間並べた無圧縮動画がある。付加情報を含めず、1 GB＝1000 MBとするとき、データ量に最も近い値を次から選べ。

  1. 0

    0.02 GB

  2. 1

    5 GB

  3. 2

    12 GB

  4. 3

    24 GB

正答3. 24 GB

無圧縮動画のデータ量は、1フレームの量×fps×秒数で求める。分を秒へ換算してから掛け、最後に指定された単位へ直す。

QUESTION 285#center_style_original_202608_0189

アナログ信号をデジタル化する過程で、標本化によって得た各時点の振幅を、あらかじめ定めた有限個の段階値のいずれかに対応させる操作を次から選べ。

  1. 0

    量子化

  2. 1

    符号化

  3. 2

    復号

  4. 3

    標本化

QUESTION 286#center_style_original_202608_0190

24ビットフルカラー画像では、1画素の赤・緑・青の各成分をそれぞれ8ビットの符号なし整数で表す。各成分の階調数と、1画素で表現できる総色数の組合せを次から選べ。

  1. 0

    各成分8階調、総色数8³色

  2. 1

    各成分24階調、総色数24³色

  3. 2

    各成分256階調、総色数256³色

  4. 3

    各成分256階調、総色数256×3色

正答と解説を確認

正答2. 各成分256階調、総色数256³色

解説

bビットで表せる値は2ᵇ通りなので、8ビットの各色成分は256階調である。独立なR・G・Bの組合せは足し算ではなく掛け算で数え、256³＝16,777,216色となる。

QUESTION 287#center_style_original_202608_0192

送信データに偶数パリティビットを1個付加し、受信側では受信した全ビットに含まれる1の個数の偶奇だけを検査する。通信中に異なる位置の2ビットが反転した場合の説明として最も適当なものを次から選べ。

  1. 0

    1の個数の偶奇が変化しないため、誤りを検出できない

  2. 1

    単純パリティから反転した二つの位置を求め、元のビット列へ訂正できる

  3. 2

    2ビットが反転すると1の個数の偶奇が変わるので、単純パリティで検出できる

  4. 3

    パリティビットが反転しなかった場合に限り、二つの誤りを検出できる

正答と解説を確認

正答0. 1の個数の偶奇が変化しないため、誤りを検出できない

解説

単純なパリティ検査で確実に検出できるのは奇数個のビット反転である。偶数個が反転すると1の個数の偶奇が変わらず、見逃す場合がある。

QUESTION 288#center_style_original_202608_0200

    (128, 0, 128)

    (255, 0, 255)

  4. 3

QUESTION 289#center_style_original_202608_0202

ディスプレイで、赤の光と青の光を同じ強さで重ね、緑の光は加えなかった。加法混色によって見える色を次から選べ。

  1. 0

    黄

  2. 1

    シアン

  3. 2

    マゼンタ

  4. 3

    白

正答と解説を確認

正答2. マゼンタ

解説

ディスプレイは赤（R）、緑（G）、青（B）の光を加える加法混色を用いる。赤＋緑は黄、緑＋青はシアン、青＋赤はマゼンタになり、三色を適切に重ねると白になる。印刷物で色材を混ぜる減法混色とは異なる。

QUESTION 290#center_style_original_202608_0203

RGB各成分を8ビットで表せる表示装置で、ある画素の赤成分を128、緑成分を128に固定し、青成分だけを変化させる。この画素が取り得る色の組合せ数を次から選べ。

  1. 0

    8通り

  2. 1

    256通り

  3. 2

    512通り

  4. 3

    65,536通り

正答と解説を確認

正答1. 256通り

解説

ある成分をbビットで自由に変えられるなら、その成分は2ᵇ通りを取れる。固定された成分は組合せ数を増やさないため、青の8ビットだけが変わる本問では2⁸＝256通りである。
