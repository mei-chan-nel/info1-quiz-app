QUESTION 461#center_style_original_202608_0355

Web記事が引用する統計値の信頼性を確かめたい。検証方法として最も適当なものを次から選べ。

  1. 0

    検索結果の先頭に出た記事なので、本文と出典を読まず正しいと判断する

  2. 1

    投稿者の知名度だけを根拠に、引用元の調査条件を確認しない

  3. 2

    見出しが自分の考えと一致すれば、数値の母集団や調査時期を確認しない

  4. 3

    引用リンクをたどって調査主体・方法・原データを確認し、独立した資料とも照合する

正答と解説を確認

正答3. 引用リンクをたどって調査主体・方法・原データを確認し、独立した資料とも照合する

解説

一次資料へ遡り、誰がどの母集団をどの方法・時期で調べたかを確認し、別系統の情報と一致するかを調べる。検索順位は関連性や最適化など多くの要因で決まり、内容の正確さを保証しないといえる。

QUESTION 462#center_style_original_202608_0356

新聞、テレビ、SNSなどの情報について、発信主体や表現方法、根拠を批判的に検討し、自ら発信・活用する能力を次から選べ。

  1. 0

    情報機器を操作する技能だけを指すコンピュータリテラシー

  2. 1

    個人データを識別しにくく加工する匿名化

  3. 2

    媒体の特性・発信主体・根拠を批判的に読み、適切に発信するメディアリテラシー

  4. 3

    多様な利用者が情報へ到達できる度合いを表す情報アクセシビリティ

正答と解説を確認

正答2. 媒体の特性・発信主体・根拠を批判的に読み、適切に発信するメディアリテラシー

解説

メディアからの情報を読み解き、評価し、主体的に表現・発信する能力を示す。機器操作も関連能力だが、新聞・テレビ・SNSの表現と根拠を批判的に扱う概念より狭い。

QUESTION 463#center_style_original_202608_0364

限定公開した写真を閲覧者が端末へ保存し、別のSNSへ転載したため、元投稿を削除した後も写真が広がり続けた。この事例に関係するデジタル情報の性質の組合せを次から選べ。

  1. 0

    機密性・完全性・可用性

  2. 1

    標本化・量子化・符号化

  3. 2

    同期性・即時性・一方向性

  4. 3

    複製性・伝播性・残存性

正答と解説を確認

正答3. 複製性・伝播性・残存性

解説

保存による複製、SNS間の伝播、削除後の残存という三つの性質に対応するといえる。情報セキュリティの三要素であり、転載と削除後の残り方を直接示す組合せとはいえない。

QUESTION 464#center_style_original_202608_0373

過去の採用結果を学習したAIが、応募者全体では高い正解率を示す一方、特定の属性を持つ応募者に不利な誤りを多く出した。運用上の対応として最も適当なものを次から選べ。

  1. 0

    全体平均の正解率だけが高ければ、少数の属性に集中する不利益は評価しない

  2. 1

    AIの数値出力は人の判断を介さないため中立で、学習データの偏りは影響しない

  3. 2

    判断理由を確認する手段と利用者が訂正を求める窓口をなくす

  4. 3

    学習データの代表性と属性別の誤り指標を検証し、人による確認・異議申立て・継続監視を設ける

正答と解説を確認

正答3. 学習データの代表性と属性別の誤り指標を検証し、人による確認・異議申立て・継続監視を設ける

解説

全体指標だけでなく属性別性能やデータ偏りを評価し、重大判断を人が監督し、影響を受ける人の救済手段を確保する。全体平均は人数の多い集団に支配され、少数集団への大きな誤りを隠す場合がある。公平性を別途検証する必要になる。

QUESTION 465#center_style_original_202608_0374

正規サービスのドメイン名がexample.comであるのに、examp1e.netへのリンクと「直ちに認証コードを入力せよ」という文面のメールを受け取った。行動として最も適当なものを次から選べ。

  1. 0

    ロゴが正規サイトと同じなので、ドメイン名の違いを無視して認証情報を入力する

  2. 1

    偽サイトでもHTTPS証明書を取得できるため、HTTPS表示だけで運営者も内容も正規と断定する

  3. 2

    緊急性を強調しているので、確認を省いてパスワードとワンタイムコードを返信する

  4. 3

    フィッシングを疑いリンクを開かず、公式アプリや既知の連絡先からサービスへ確認する

正答と解説を確認

正答3. フィッシングを疑いリンクを開かず、公式アプリや既知の連絡先からサービスへ確認する

解説

正規サービスのexample.comとは異なるexamp1e.netへのリンクと、判断を急がせて認証コードを入力させる文面はフィッシングの典型的な手口である。メール内のリンクを使わず、公式アプリや自分で確認した正規URLから接続し、HTTPSの表示だけで正規の運営者だとは判断しない。

  1. 0

    画面や手元を背後から観察するショルダーハッキング

    多数端末からサービスへ負荷を集中させるDDoS攻撃

  1. 0

    利用者IDとパスワードで主体を確かめる認証

  2. 1

    操作内容と時刻を後から追跡できるよう記録する監査

  3. 2

    通信路を暗号化して盗聴を防ぐTLS

  4. 3

    認証済み利用者へ対象操作を許すか権限で判断する認可

役割とアクセス権を照合し、管理者画面の閲覧を許可するか決める処理と捉えられる。IDとパスワードの確認は既に成功しており、その後の権限判定を問うている。

QUESTION 468#center_style_original_202608_0377

顔認証端末へ本人の顔写真を見せて認証を突破しようとする提示攻撃への対策として最も適当な機能を次から選べ。

  1. 0

    登録写真との画素の一致率を厳しく設定し、撮影対象が立体かどうかは判定しない

  2. 1

    顔が一定時間カメラに写っていることだけで、写真ではなく生体だと判定する

  3. 2

    認証失敗回数を少なく制限し、入力された顔が写真か生体かは区別しない

  4. 3

    まばたき、微細な動き、奥行きなどから撮影対象が生体であることを確認するライブネス検知

正答と解説を確認

正答3. まばたき、微細な動き、奥行きなどから撮影対象が生体であることを確認するライブネス検知

解説

顔の特徴が登録情報と一致するかという照合と、カメラの前にいるものが生きた本人かという確認は別である。写真や動画を使う提示攻撃には、まばたき・動き・奥行きなどを調べるライブネス検知を組み合わせる。

「便利な無料ツール」と偽って利用者にインストールさせ、実行後に攻撃者が端末を遠隔操作できるようにするマルウェアの分類を次から選べ。

  1. 0

    入力や閲覧履歴を密かに収集するスパイウェア

  2. 1

    ファイルを暗号化して身代金を要求するランサムウェア

  3. 2

    自己増殖して他の機器へ広がるワーム

  4. 3

    有用なソフトを装って不正機能を実行させるトロイの木馬

正答と解説を確認

正答3. 有用なソフトを装って不正機能を実行させるトロイの木馬

解説

正規・有用に見せてインストールさせ、裏で遠隔操作機能を動かす特徴に合う。情報収集を主目的とする分類で、便利なツールを装う偽装実行の特徴を直接表さない。

QUESTION 470#center_style_original_202608_0384

電子メールで受け取ったファイルの表示名が「歓迎会の写真.jpg.exe」であった。拡張子が全て表示されているものとして、行動を次から選べ。

  1. 0

    ファイル名の途中に.jpgがあれば、末尾が.exeでも画像として開いてよい

  2. 1

    セキュリティソフトが直ちに警告しなければ、画像として開いてよい

  3. 2

    差出人の表示名が知人と同じなら、添付ファイルの末尾を確認せず開く

  4. 3

    末尾の.exeは実行形式を示すため開かず、別経路で送信元と安全性を確認する

正答と解説を確認

正答3. 末尾の.exeは実行形式を示すため開かず、別経路で送信元と安全性を確認する

解説

ファイル形式の手掛かりになるのは通常、最後の拡張子である。二重拡張子は画像に見せかける手口に使われる。表示名や検査結果の一つだけを信頼せず、実行形式は開かないで、既知の連絡先から送信事実を確認する。
