QUESTION 451#center_style_original_202608_0337

指紋や顔などを用いる生体認証の利点と注意点の組合せとして最も適当なものを次から選べ。

  1. 0

    身体特徴は全員で同じものを共有できるため、共用アカウントの認証に最適である

  2. 1

    生体情報は漏えいしてもパスワードのように何度でも容易に変更できる

  3. 2

    照合しきい値を調整すれば、本人拒否率と他人受入率を同時に0にできる

  4. 3

    認証情報を持ち歩く負担を減らし得るが、身体特徴は変更しにくく、本人拒否や他人受入れも起こり得る

正答と解説を確認

正答3. 認証情報を持ち歩く負担を減らし得るが、身体特徴は変更しにくく、本人拒否や他人受入れも起こり得る

解説

所持品や記憶への依存を減らせる一方、生体特徴の変更困難性、漏えい時の影響、測定誤差による誤判定を考慮する必要になる。生体認証は個人ごとの差を利用するもので、全員が同じ特徴を共有する前提では本人を区別できない。

QUESTION 452#center_style_original_202608_0341

情報セキュリティの三要素と、それを主に高める対策の対応として最も適当なものを次から選べ。

  1. 0

    機密性―冗長化、完全性―アクセス制御、可用性―改ざん検出

  2. 1

    機密性―改ざん検出、完全性―冗長化、可用性―アクセス制御

  3. 2

    機密性―アクセス制御、完全性―改ざん検出、可用性―冗長化

  4. 3

    機密性―全員への公開、完全性―変更履歴の削除、可用性―単一障害点の追加

正答と解説を確認

正答2. 機密性―アクセス制御、完全性―改ざん検出、可用性―冗長化

解説

機密性は「見せない」、完全性は「正しく保つ」、可用性は「必要なとき使える」と整理する。アクセス制御、改ざん検出、冗長化をこの目的へ対応させる。

QUESTION 453#center_style_original_202608_0342

アクセス権を担当者だけに限定すべき顧客名簿を、誤って誰でも閲覧できるクラウド領域へ置いた。主に損なわれた情報セキュリティの性質を次から選べ。

  1. 0

    機密性

  2. 1

    可用性

  3. 2

    完全性

  4. 3

    真正性

正答と解説を確認

正答0. 機密性

解説

本来許可されていない人が顧客名簿を閲覧できる状態になり、情報を秘密に保つ機密性が損なわれた。可用性は必要な利用者が情報を利用できる性質で、本件の中心は利用不能ではなく未許可者への公開と捉えられる。

QUESTION 454#center_style_original_202608_0343

ソフトウェアを配布サイトからダウンロードし、そのファイルから計算した暗号学的ハッシュ値を、配布元が別の安全な方法で示した正しいハッシュ値と比較したところ、一致しなかった。このときの対応として最も適当なものを次から選べ。

  1. 0

    ファイル名が配布元の表示と同じなので、内容も同一だと判断して実行する

  2. 1

    改変や破損の可能性があるため実行せず、入手経路を確認して再取得し、もう一度ハッシュ値を照合する

  3. 2

    ハッシュ値は機密性だけを確認するものなので、不一致でもファイルの内容には関係しない

  4. 3

    ダウンロードしたファイルを自分で暗号化すれば、配布元のハッシュ値と一致する

正答と解説を確認

正答1. 改変や破損の可能性があるため実行せず、入手経路を確認して再取得し、もう一度ハッシュ値を照合する

解説

暗号学的ハッシュ関数では、入力するビット列が変わると通常は異なるハッシュ値になる。配布元の正しい値と一致しない場合、通信中の破損や第三者による改変などの可能性があるため、そのファイルの完全性は確認できない。実行を止め、信頼できる入手先から再取得して照合し直す。

QUESTION 455#center_style_original_202608_0344

一つの地域で大規模災害が起きてもサービスを継続できるよう、データを同期した予備サーバを離れた地域に配置した。主に高める情報セキュリティの性質を次から選べ。

  1. 0

    可用性

  2. 1

    完全性

  3. 2

    機密性

  4. 3

    匿名性

正答と解説を確認

正答0. 可用性

解説

一地域の設備が使えなくても別地域へ切り替えてサービスを利用可能にする冗長化で、可用性を主に高めるといえる。同期時の検証は完全性にも関係するが、地域分散した予備設備を置く主目的は停止時のサービス継続である。

QUESTION 456#center_style_original_202608_0345

切り離した複数世代のバックアップを定期取得し、復元テストも行っている。この対策だけでは防げないランサムウェア被害を次から選べ。

  1. 0

    攻撃者が暗号化前に機密データを外部へ持ち出して公開すると脅迫すること

  2. 1

    暗号化された業務データを感染前の世代へ戻して復旧すること

  3. 2

    一つのバックアップ世代が破損したときに別世代を使うこと

  4. 3

    復元手順の不備を事前のテストで発見すること

正答と解説を確認

正答0. 攻撃者が暗号化前に機密データを外部へ持ち出して公開すると脅迫すること

解説

バックアップはデータ復旧に役立つが、既に持ち出された秘密情報を回収したり公開を阻止したりする対策にはならない。感染前で安全なバックアップが残っていれば、暗号化されたデータを復旧できる可能性があり、これは対策の効果と捉えられる。

QUESTION 457#center_style_original_202608_0346

多数のサービスで異なるパスワードを安全に管理するため、パスワード管理ツールを利用する。運用方法として最も適当なものを次から選べ。

  1. 0

    管理ツールの入口となるパスワードを、端末を共有する家族も読める通常のメモへ保存する

  2. 1

    サービスごとに異なる長い値を生成し、管理ツールは長いマスターパスワードと多要素認証で守る

  3. 2

    管理ツールへ保存すれば使い回しの危険はなくなると考え、全サービスへ同じ値を登録する

  4. 3

    端末を離れた後も入力を省けるよう、管理ツールの自動ロックを無効にして開いたままにする

正答と解説を確認

正答1. サービスごとに異なる長い値を生成し、管理ツールは長いマスターパスワードと多要素認証で守る

解説

パスワード管理ツールは、サービスごとに異なる長いパスワードを覚える負担を減らせる。一方、管理ツールの認証が破られると影響が大きいため、マスターパスワードを十分に長くし、多要素認証や自動ロックも利用する。ツールへ保存するだけで、同じパスワードの使い回しが安全になるわけではない。

QUESTION 458#center_style_original_202608_0347

ランサムウェアの典型的な動作と攻撃者の要求を述べたものを次から選べ。

  1. 0

    利用者の行動を密かに収集することを主目的とするスパイウェア

  2. 1

    自己増殖してネットワークへ広がることを主特徴とするワーム

  3. 2

    正規ソフトを装って不正機能を実行させるトロイの木馬

  4. 3

    ファイルやシステムを暗号化し、復旧などと引換えに金銭を要求するランサムウェア

正答と解説を確認

正答3. ファイルやシステムを暗号化し、復旧などと引換えに金銭を要求するランサムウェア

解説

ランサムウェア対策では、更新や不審ファイル対策に加え、元データと同時に暗号化されない世代別バックアップを用意する。金銭を払っても復旧が保証されるわけではない。

QUESTION 459#center_style_original_202608_0353

日本の著作権法で著作者人格権に含まれ、著作物の公表時に著作者名を表示するか、どの名義で表示するかを決める権利を次から選べ。

  1. 0

    商標権

  2. 1

    特許権

  3. 2

    意匠権

  4. 3

    氏名表示権

正答と解説を確認

正答3. 氏名表示権

解説

氏名表示権は、著作物を公衆へ提示・提供するときに実名・変名を表示するか、表示しないかを決める著作者人格権である。商標権は商品・役務の出所を識別する標識を登録によって保護する産業財産権で、著作者人格権とはいえない。

QUESTION 460#center_style_original_202608_0354

所得、地域、年齢、障害、教育機会などの違いにより、情報通信技術への接続や利用能力、得られる利益に格差が生じる問題を表す用語を次から選べ。

  1. 0

    デジタルデバイド

  2. 1

    フィッシング

  3. 2

    VDT症候群

  4. 3

    著作権侵害

正答と解説を確認

正答0. デジタルデバイド

解説

デジタルデバイドは、ICTへアクセスできる人とできない人、十分活用できる人とできない人の間に生じる格差を指す。フィッシングは実在組織を装う偽サイト等で認証情報をだまし取る攻撃で、社会的な利用格差の名称とはいえない。
