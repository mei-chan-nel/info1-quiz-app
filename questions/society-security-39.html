QUESTION 381#center_style_original_202608_0087

ファイルを暗号化して復号と引換えに金銭を要求するプログラムと、自己増殖してネットワークへ広がるプログラムを、この順に分類した組合せを次から選べ。

  1. 0

    トロイの木馬、ランサムウェア

  2. 1

    ランサムウェア、ワーム

  3. 2

    スパイウェア、トロイの木馬

  4. 3

    ワーム、ランサムウェア

正答と解説を確認

正答1. ランサムウェア、ワーム

解説

マルウェアは主な動作で区別する。ファイルの暗号化と金銭要求はランサムウェア、自己増殖による伝播はワーム、有用なソフトを装う侵入方法はトロイの木馬の特徴である。

QUESTION 382#center_style_original_202608_0093

自動車メーカーが部品メーカー向けの専用サイトで部品を発注する取引形態を次から選べ。

  1. 0

    BtoC

  2. 1

    CtoC

  3. 2

    CtoG

  4. 3

    BtoB

正答と解説を確認

正答3. BtoB

解説

自動車メーカーと部品メーカーはいずれも企業なので、企業間取引を示すBtoBに当たる。BtoCは企業が一般消費者へ商品やサービスを提供する取引で、企業間の部品発注とはいえない。

QUESTION 383#center_style_original_202608_0098

「生成AIの教育利用」について、検索結果を絞り込みながら信頼できる資料へ到達する方法を次から選べ。

  1. 0

    目的に応じて語句を組み合わせ、資料の発行主体、発行日、資料種別、根拠を確かめる

  2. 1

    最初に表示された自動要約だけを読み、発行元と原文を確認しない

  3. 2

    検索語を一語に固定し、目的に合わない結果でも語句を変更しない

  4. 3

    検索結果に広告として掲載されていれば、学術資料より優先して採用する

正答と解説を確認

正答0. 目的に応じて語句を組み合わせ、資料の発行主体、発行日、資料種別、根拠を確かめる

解説

検索語を調整して範囲を絞り、誰がいつ何を根拠に作った資料かを確認すれば、目的に適した資料を評価可能になる。自動要約は原文の条件や留保を省く場合があり、発行元と原資料を見なければ信頼性を評価できない。

QUESTION 384#center_style_original_202608_0099

不正ログインの試行を事後調査できるよう、認証ログに記録する情報の組合せとして最も適当なものを次から選べ。

  1. 0

    成功した認証だけを記録し、失敗した試行は残さない

  2. 1

    試行時刻、利用者識別子、送信元、認証の成功・失敗

  3. 2

    入力されたパスワードと秘密の質問の答えを、そのまま記録する

  4. 3

    利用者識別子だけを記録し、時刻・送信元・結果は残さない

正答と解説を確認

正答1. 試行時刻、利用者識別子、送信元、認証の成功・失敗

解説

ログは『いつ、誰として、どこから、何を試し、どうなったか』を結び付けると調査に役立つ。一方、パスワードなどの秘密情報をそのまま残してはいけない。必要な項目、保存期間、閲覧権限、改ざん防止も併せて設計する。

QUESTION 385#center_style_original_202608_0100

ランサムウェア感染時にも復元可能性を高めるバックアップ方法を次から選べ。

  1. 0

    元データと同じ端末内の別フォルダだけにコピーを置き、必要時にそこから戻す

  2. 1

    複数世代を保持し、一部は通常のネットワークから切り離して保管し、定期的に復元テストを行う

  3. 2

    感染を確認した後で、暗号化済みファイルだけを同じ端末内の媒体へコピーする

  4. 3

    正常時に一度だけ別媒体へコピーし、以後は媒体の状態や復元手順を確かめない

正答と解説を確認

正答1. 複数世代を保持し、一部は通常のネットワークから切り離して保管し、定期的に復元テストを行う

解説

世代管理で感染前の時点を選べ、切離し保管で同時暗号化を避け、復元テストで実際に戻せることを確認可能になる。同じ端末や常時アクセス可能な場所だけでは、ランサムウェアによって元データと同時に暗号化されるおそれがある。

QUESTION 386#center_style_original_202608_0109

サービス事業者が本人確認のため、日本の個人情報保護法上の個人識別符号に該当する旅券番号を収集する。この情報の扱いを次から選べ。

  1. 0

    暗号化すれば、利用目的・保存期間・アクセス権を検討しなくてよい

  2. 1

    利用目的を明確にし、必要な者だけにアクセスを限定して安全に管理する

  3. 2

    数字と文字の列なので、特定の個人に対応しても個人情報ではない

  4. 3

    公的機関が発行した番号なので、当初の目的と無関係なデータとも自由に統合できる

正答と解説を確認

正答1. 利用目的を明確にし、必要な者だけにアクセスを限定して安全に管理する

解説

本人確認に必要な範囲で目的を定め、アクセスできる担当者を限定し、漏えい等を防ぐ安全管理を実施する。暗号化は漏えい時の読取りを抑える一手段だが、目的限定、保存期間、アクセス制御など他の管理事項を不要にしない。

QUESTION 387#center_style_original_202608_0111

銀行を装うメールのリンク先でIDとパスワードの入力を求められた。フィッシング被害を避ける行動を次から選べ。

  1. 0

    ロゴが銀行と同じに見えれば、リンク先URLを確認せず入力する

  2. 1

    期限を示して急がせる文面ほど正規連絡だと判断し、直ちに認証情報を送る

  3. 2

    メール内のリンクを使わず、公式アプリや自分で確認した正規URLから連絡内容を確認する

  4. 3

    確認を簡単にするため、他サービスでも同じパスワードを使う

正答と解説を確認

正答2. メール内のリンクを使わず、公式アプリや自分で確認した正規URLから連絡内容を確認する

解説

メールが指定した経路を避け、事前に確認した公式の入口からアクセスすれば偽サイトへ誘導される危険を下げられる。ロゴや画面は複製可能なので、見た目だけでは銀行が運営する正規サイトだと確認できない。

QUESTION 388#center_style_original_202608_0114

オンライン授業サーバを冗長化し、稼働中の機器が故障したとき予備機へ切り替えてサービスを継続する。主として高める情報セキュリティの要素を次から選べ。

  1. 0

    完全性

  2. 1

    機密性

  3. 2

    可用性

  4. 3

    否認防止

正答と解説を確認

正答2. 可用性

解説

予備機への切替えによって、障害時にもサービスを使える状態を保つ対策は可用性を高める。完全性は情報が正確で不正に変更されていない性質であり、サービスの停止時間を短くする可用性とは区別する。

QUESTION 389#center_style_original_202608_0115

成績ファイルの作成時に信頼できる場所へ保存した暗号学的ハッシュ値と、後から同じファイルから計算したハッシュ値を照合した。主として確認する情報セキュリティの要素を次から選べ。

  1. 0

    機密性

  2. 1

    可用性

  3. 2

    匿名性

  4. 3

    完全性

正答と解説を確認

正答3. 完全性

解説

二つのハッシュ値の一致を調べることで、保存後に内容が変更されていないかという完全性を確かめる。ハッシュ値の照合はファイル本文を暗号化して読めなくする処理ではなく、機密性を直接確保しないといえる。

QUESTION 390#center_style_original_202608_0119

公開鍵暗号方式で、送信者Aが受信者Bだけが復号できるように平文を暗号化して送る。Bの秘密鍵がBだけに管理されているときの鍵の使い方を次から選べ。

  1. 0

    Bの公開鍵で暗号化し、Bの秘密鍵で復号する

  2. 1

    Aの公開鍵で暗号化し、Aの秘密鍵で復号する

  3. 2

    Aの秘密鍵だけで暗号化し、Bの公開鍵で復号する

  4. 3

    Bの秘密鍵をAへ渡して暗号化し、Bの公開鍵で復号する

正答と解説を確認

正答0. Bの公開鍵で暗号化し、Bの秘密鍵で復号する

解説

誰でも入手できるBの公開鍵で暗号化し、対応するBの秘密鍵を持つBだけが復号する。Aの鍵ペアを使うとAの秘密鍵を持つAが復号主体となり、Bだけに読ませる目的にならないといえる。
