QUESTION 171#center_style_original_202608_0263

URL「https://www.mei-chan-nel.com/info1-quiz-app/app/」から、ドメイン名を取り出したものを次から選べ。

  1. 0

    https

  2. 1

    www.mei-chan-nel.com

  3. 2

    /info1-quiz-app/app/

  4. 3

    https://www.mei-chan-nel.com

正答と解説を確認

正答1. www.mei-chan-nel.com

解説

URLは、通信方式を示すスキーム、接続先を示すドメイン名、その中の位置を示すパスなどに分けて読む。`https://www.mei-chan-nel.com/info1-quiz-app/app/`では、`https`がスキーム、`www.mei-chan-nel.com`がドメイン名、`/info1-quiz-app/app/`がパスである。

QUESTION 172#center_style_original_202608_0264

TCP/IPの4階層モデルでIPが属し、IPアドレスに基づくパケットの配送やルーティングを担う層を次から選べ。

  1. 0

    アプリケーション層

  2. 1

    トランスポート層

  3. 2

    インターネット層

  4. 3

    ネットワークインタフェース層

正答と解説を確認

正答2. インターネット層

解説

IPはインターネット層に属し、IPアドレスを使って別のネットワーク間でパケットを配送する。アプリケーション層にはHTTPやDNSなど、利用者向けサービスに近いプロトコルが属する。

QUESTION 173#center_style_original_202608_0274

同じLAN内で複数のコンピュータやプリンタを有線接続し、宛先に応じて必要な接続先へデータを転送する装置を次から選べ。

  1. 0

    DNSサーバ

  2. 1

    スイッチングハブ

  3. 2

    ルータ

  4. 3

    Webサーバ

正答と解説を確認

正答1. スイッチングハブ

解説

スイッチングハブは、同じLAN内の複数の機器を接続し、宛先に応じてデータを転送する。ルータは異なるネットワーク間を中継する。装置名だけでなく、同じLAN内か、異なるネットワーク間かを区別する。

QUESTION 174#center_style_original_202608_0275

同じ教室のLANで、コンピュータからプリンタへデータを送る。スイッチングハブの働きとして最も適当なものを次から選べ。

  1. 0

    異なるネットワークまでの経路をIPアドレスで選び、インターネットへ中継する

  2. 1

    同じLAN内で機器の接続先を学習し、宛先に対応するポートへデータを転送する

  3. 2

    ドメイン名をIPアドレスへ変換して、Webサイトの接続先を通知する

  4. 3

    端末へIPアドレスを自動設定し、使用期間を決めて貸し出す

正答と解説を確認

正答1. 同じLAN内で機器の接続先を学習し、宛先に対応するポートへデータを転送する

解説

スイッチングハブは、同じLAN内で機器同士のデータを転送する。接続機器とポートの対応を学習し、宛先に応じて転送先を絞る。異なるネットワーク間の中継はルータ、名前の解決はDNS、IPアドレスの自動設定はDHCPが担当する。

QUESTION 175#center_style_original_202608_0276

WebサーバのIPアドレスを変更した直後、利用者側のDNSキャッシュに、有効期間内の古いIPアドレスが残っていた。起こり得る現象を次から選べ。

  1. 0

    権威DNSを書き換えると、利用者側の全キャッシュも同じ内容へ直ちに更新される

  2. 1

    設定された有効期間が終わるまで古いIPアドレスを使い、新しいサーバへ到達できない場合がある

  3. 2

    古い情報が残る間、端末は新旧両方のWebサーバへ必ず同時に接続する

  4. 3

    DNSキャッシュはホスト名だけを保存し、対応するIPアドレスを保存しないため影響はない

正答と解説を確認

正答1. 設定された有効期間が終わるまで古いIPアドレスを使い、新しいサーバへ到達できない場合がある

解説

DNSは、名前解決の結果を一定期間キャッシュに保存する。WebサーバのIPアドレスを変更しても、保存済みの有効期間が終わるまでは古いアドレスが返され、移行先へ接続できない場合がある。変更と同時に全ての端末へ反映されるとは限らない。

QUESTION 176#center_style_original_202608_0278

校内LANの端末からインターネット上のWebサーバへパケットを送るとき、異なるネットワークの間を中継する装置を次から選べ。

  1. 0

    ルータ

  2. 1

    スイッチングハブ

  3. 2

    DNSサーバ

  4. 3

    Webサーバ

正答と解説を確認

正答0. ルータ

解説

ルータは異なるネットワークを接続し、宛先IPアドレスを基にパケットの転送先を決める。同じLAN内の転送を主に担当するスイッチングハブとは役割が異なる。家庭では、LANとインターネットの境界に置かれる機器がこの役割を担う。

QUESTION 177#center_style_original_202608_0317

家庭内LANの端末から、インターネット上の別のネットワークにあるWebサーバへパケットを送る。異なるネットワークの間を中継する装置を次から選べ。

  1. 0

    同じLAN内の機器を有線接続するスイッチングハブ

  2. 1

    無線端末をLANへ接続する無線アクセスポイント

  3. 2

    宛先IPアドレスを基に異なるネットワーク間を中継するルータ

  4. 3

    ドメイン名をIPアドレスへ変換するDNSサーバ

正答と解説を確認

正答2. 宛先IPアドレスを基に異なるネットワーク間を中継するルータ

解説

ルータは、異なるネットワークを接続し、宛先IPアドレスに応じてパケットを中継する。同じLAN内の転送はスイッチングハブ、無線端末の接続は無線アクセスポイント、名前解決はDNSサーバが担当する。

QUESTION 178#center_style_original_202608_0318

端末AからサーバCへのパケットはルーターBを1台経由する。A―B間の伝送遅延が10 ms、B―C間が30 msで、処理遅延・待ち時間・再送を無視できるとき、AからCまでの片道遅延を次から選べ。

  1. 0

    20 ms

  2. 1

    30 ms

  3. 2

    40 ms

  4. 3

    300 ms

正答と解説を確認

正答2. 40 ms

解説

複数区間を順に通る片道遅延は、各区間の遅延を加える。ここでは10＋30＝40 msである。往復時間を求める場合は復路の遅延も加え、処理遅延や待ち時間が指定されていればそれらも含める。

QUESTION 179#center_style_original_202608_0320

家庭がインターネットサービスプロバイダ（ISP）と契約して受ける中心的なサービスを次から選べ。

  1. 0

    独自ドメイン名の登録だけを行うレジストラ業務

  2. 1

    Webページを保存・配信するWebホスティングだけ

  3. 2

    公開鍵証明書を発行してサイト運営者を認証する認証局業務だけ

  4. 3

    インターネットへの接続回線や接続用IPアドレスなどを提供する

正答と解説を確認

正答3. インターネットへの接続回線や接続用IPアドレスなどを提供する

解説

回線とアドレス割当て等により、家庭のネットワークをインターネットへ接続するといえる。ドメイン登録は関連サービスになり得るが、家庭がISPへ求める中心的な接続サービスそのものとはいえない。

QUESTION 180#center_style_original_202608_0330

ネットワーク通信で用いられるTCPの働きとして最も適当なものを次から選べ。

  1. 0

    ドメイン名をIPアドレスへ変換して、接続先を調べる

  2. 1

    通信内容を暗号化し、Webサイトの掲載内容が正しいことまで保証する

  3. 2

    データの順序を管理し、届かなかった部分を再送して信頼性を高める

  4. 3

    宛先IPアドレスを基に、ルータ間でパケットの経路を選ぶ

正答と解説を確認

正答2. データの順序を管理し、届かなかった部分を再送して信頼性を高める

解説

TCPは、送ったデータが届いたかを確認し、欠けた部分を再送し、順序を整えることで通信の信頼性を高める。IPが宛先までパケットを運ぶ役割を担うのに対し、TCPはアプリケーション間でデータを正しい順序で受け渡しやすくする。
