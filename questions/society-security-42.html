QUESTION 411#center_style_original_202608_0177

組織で使用する端末にコンピュータウイルス感染の疑いが生じた。被害拡大の防止と適切な調査のために行う初動として最も適当なものを次から選べ。

  1. 0

    感染の有無を確かめるため、疑わしいファイルをほかの端末でも実行する

  2. 1

    端末をネットワークから切り離し、組織の手順に従って担当部署へ連絡する

  3. 2

    証拠を残さないよう、端末のログと疑わしいファイルを直ちに削除する

  4. 3

    業務を止めないよう、端末を接続したままウイルス対策ソフトだけを停止する

正答と解説を確認

正答1. 端末をネットワークから切り離し、組織の手順に従って担当部署へ連絡する

解説

ネットワークからの隔離は、ほかの端末への感染や外部との不正通信を抑える。続いて所定の窓口へ報告し、調査・復旧の指示を受ける。疑わしいファイルを別端末で実行すると、感染範囲を広げるおそれがある。検体の確認は隔離された環境で担当者が実施する。

QUESTION 412#center_style_original_202608_0178

他人の利用者IDとパスワードを本人の承諾なく用いて、アクセス制御されたオンラインサービスへログインする行為に関する説明として最も適当なものを次から選べ。

  1. 0

    閲覧だけでデータを変更しなければ、不正アクセス行為には該当しない

  2. 1

    認証情報を無断で用いたログインは、不正アクセス禁止法に違反する可能性がある

  3. 2

    入力した認証情報が正しければ、利用者本人でなくても適法である

  4. 3

    金銭的な被害が発生した場合に限り、不正アクセス行為となる

正答と解説を確認

正答1. 認証情報を無断で用いたログインは、不正アクセス禁止法に違反する可能性がある

解説

他人の識別符号を無断で入力し、アクセス制御機能による利用制限を解除して利用可能な状態にする行為は、不正アクセス禁止法の規制対象になり得る。不正アクセス行為に該当するかは、ログイン後にデータを変更したかではなく、他人の識別符号を無断で入力して利用制限を解除したかなどで判断される。

QUESTION 413#center_style_original_202608_0186

市販の小説を購入した本人が、仕事ではなく自分の学習だけに使うため、自宅の機器で必要な部分を複製する。技術的保護手段の回避や違法配信からの取得はない。この行為に関する著作権法上の説明として最も適当なものを次から選べ。

  1. 0

    購入した著作物であれば、複製物をインターネットで一般公開しても私的使用となる

  2. 1

    私的使用を目的とする複製についての権利制限規定が適用され得る

  3. 2

    購入者本人の学習目的でも、許諾のない複製は私的使用には当たらない

  4. 3

    私的使用の範囲なら、技術的保護手段を回避した複製も通常の複製と同じ扱いになる

正答と解説を確認

正答1. 私的使用を目的とする複製についての権利制限規定が適用され得る

解説

個人的な学習のために、使用者本人が自宅で必要部分を複製するという条件は、私的使用のための複製に関する権利制限の対象となり得る。購入したことだけで著作権が消えるわけではなく、技術的保護手段の回避など、問題文にない事情があれば結論が変わり得る。

QUESTION 414#center_style_original_202608_0187

個人用コンピュータを安全に利用するための行動として最も適当なものを次から選べ。

  1. 0

    更新通知を装う詐欺を避けるため、正規の更新通知も含め全て無視する

  2. 1

    復旧に使えるよう、バックアップ媒体を常時コンピュータへ接続しておく

  3. 2

    ログインできなくなる事態に備え、IDとパスワードを友人と共有する

  4. 3

    OSやアプリ、ウイルス対策ソフトを正規の更新手段で最新の状態に保つ

正答と解説を確認

正答3. OSやアプリ、ウイルス対策ソフトを正規の更新手段で最新の状態に保つ

解説

正規の更新機能や公式サイトを用いて修正プログラムを適用すると、既知の脆弱性を悪用される危険を減らせる。偽通知には注意が必要だが、全ての更新を無視すると既知の脆弱性が残る。通知のリンクを安易に開かず、正規の更新機能から確かめる。

QUESTION 415#center_style_original_202608_0196

SNSに公開した写真を後から削除したが、他者の端末や転載先には残っていた。この事例から分かるデジタル情報の性質と、公開前に取るべき対策の組合せとして最も適当なものを次から選べ。

  1. 0

    元投稿を削除すれば全ての複製も自動的に消えるので、公開前の確認は不要である

  2. 1

    複製・伝播・残存しやすいので、公開範囲や位置情報、他者の写り込みを確認する

  3. 2

    デジタル画像は複製時に大きく劣化するため、鮮明な転載が残る可能性は低い

  4. 3

    一度共有されると肖像や著作権に関する権利は消滅するので、写り込みは確認しなくてよい

正答と解説を確認

正答1. 複製・伝播・残存しやすいので、公開範囲や位置情報、他者の写り込みを確認する

解説

デジタル情報は、元を残したまま同じ品質で複製・転送しやすい。公開後は保存、転載、画面取得など管理できない複製が生まれ得るため、『後で消せるか』ではなく『複製されても問題ないか』を公開前に判断する。

QUESTION 416#center_style_original_202608_0198

SNSで多数回共有されているが、出典が示されていない情報を見つけた。信頼性を判断して再発信する前の行動として最も適当なものを次から選べ。

  1. 0

    共有回数が多いこと自体を正しさの証拠として、内容を確認せず再発信する

  2. 1

    自分の予想に合う部分だけを根拠として、発信者を確認せず再発信する

  3. 2

    発信者・一次情報・根拠を調べ、独立した信頼できる資料とも照合する

  4. 3

    既存の報道機関が扱っていないという理由だけで、内容を誤りと断定する

正答と解説を確認

正答2. 発信者・一次情報・根拠を調べ、独立した信頼できる資料とも照合する

解説

情報の出所を一次情報までたどり、根拠を評価し、独立した複数の信頼できる資料で一致を確かめるのが適切である。共有回数は注目度を示しても、事実確認の結果を示すとは限らない。誤情報も大量に拡散され得る。

QUESTION 417#center_style_original_202608_0199

組織が情報資産を安全に扱い、事故発生時にも業務を継続・復旧できるようにする対策の組合せとして最も適当なものを次から選べ。

  1. 0

    担当部署の全員へ管理者権限を与え、操作ログは事故が起きた後から取得する

  2. 1

    定期的な研修と注意喚起を行えば、アクセス制御やバックアップは設けなくてよい

  3. 2

    管理を簡単にするため全員で一つのパスワードを共有し、長期間変更しない

  4. 3

    情報セキュリティ方針、最小限のアクセス権、復元可能なバックアップ、事故対応手順を整える

正答と解説を確認

正答3. 情報セキュリティ方針、最小限のアクセス権、復元可能なバックアップ、事故対応手順を整える

解説

情報セキュリティは、事故を防ぐ対策だけでなく、起きた事故を検知し、影響を抑え、復旧する対策まで含めて考える。教育・権限・ログ・バックアップ・対応手順は役割が異なるため、単独ではなく多層的に組み合わせる。

QUESTION 418#center_style_original_202608_0201

写真に「CC BY-NC 4.0」と表示されている。この写真を一部切り抜き、学校が無料配布する資料に掲載したい。ライセンスに沿う利用方法を次から選べ。

  1. 0

    作者名など必要な表示を行い、変更したことを示したうえで、非営利の無料資料として利用する

  2. 1

    無料配布であれば作者名の表示は省略できると考え、出典を書かずにそのまま掲載する

  3. 2

    NCは改変禁止を意味すると考え、切り抜きをやめれば作者名を示さずに掲載できる

  4. 3

    BYは作者名の表示だけを求める条件なので、同じ写真を広告へ掲載して販売促進にも利用する

正答と解説を確認

正答0. 作者名など必要な表示を行い、変更したことを示したうえで、非営利の無料資料として利用する

解説

CCライセンスは記号を分けて読む。BYは表示、NCは非営利、NDは改変禁止、SAは改変物にも同じ条件を引き継ぐことを表す。複数の記号があれば、その条件を組み合わせて守る。

QUESTION 419#center_style_original_202608_0206

公開Webサーバを内部ネットワークとは別の区画に置き、ファイアウォールで通信を制御する。インターネットの利用者にはHTTPSを提供し、それ以外の不要な通信を抑える受信規則として最も適当なものを次から選べ。

  1. 0

    送信元や宛先にかかわらず、全てのポートへの通信を許可する

  2. 1

    内部ネットワークの全端末宛てにTCPポート443を転送し、Webサーバ宛ては拒否する

  3. 2

    インターネットから公開WebサーバのTCPポート443宛てだけを許可し、その他は既定で拒否する

  4. 3

    公開Webサーバへの通信を全て拒否し、ファイアウォールを通らない直結回線を追加する

正答と解説を確認

正答2. インターネットから公開WebサーバのTCPポート443宛てだけを許可し、その他は既定で拒否する

解説

提供するHTTPSの宛先とポートに限定して許可し、明示していない通信を拒否すれば、公開要件を満たしつつ攻撃面を抑えられる。不要なサービスまで外部へ公開され、攻撃を受ける入口が増える。必要な通信だけを許可する最小権限の規則が必要である。

QUESTION 420#center_style_original_202608_0222

実在するオンラインサービスの運営者を装った偽サイトを作り、不正アクセスに用いる目的で利用者にIDとパスワードを入力させて取得する行為に関する説明として最も適当なものを次から選べ。

  1. 0

    偽サイトであることを画面の隅に小さく書けば、認証情報の取得目的にかかわらず適法になる

  2. 1

    不正アクセス禁止法が禁止する識別符号の入力を不正に要求する行為や不正取得に該当し得る

  3. 2

    入力したのが利用者本人なら、だまして認証情報を取得しても法的な問題は生じない

  4. 3

    実際にそのIDでログインするまで、認証情報をだまし取る行為自体は同法の規制対象になり得ない

正答と解説を確認

正答1. 不正アクセス禁止法が禁止する識別符号の入力を不正に要求する行為や不正取得に該当し得る

解説

他人の識別符号を不正アクセスに使う目的で取得する行為や、アクセス管理者を装って入力を要求するフィッシング行為は同法の規制対象になり得る。表示を小さく付けるだけで、アクセス管理者を装って不正な目的で認証情報を要求する行為が正当化されるわけとはいえない。
