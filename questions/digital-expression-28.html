QUESTION 271#center_style_original_202608_0117

CPUの構成要素のうち、主記憶装置から取り出した命令を解読し、ほかの装置へ動作の指示を出すものを次から選べ。

  1. 0

    入力装置

  2. 1

    出力装置

  3. 2

    記憶装置

  4. 3

    制御装置

正答と解説を確認

正答3. 制御装置

解説

QUESTION 272#center_style_original_202608_0120

1 MB＝1000 KBとする。3個のセンサがそれぞれ1分当たり20 KBのデータを出力する。全センサを30日間連続稼働したときの総データ量をMBで表した値を次から選べ。

  1. 0

    2592 MB

  2. 1

    864 MB

  3. 2

    86.4 MB

  4. 3

    25920 MB

正答と解説を確認

正答0. 2592 MB

解説

一定の発生量なら総量＝単位時間当たりの量×時間×個数で求める。日数を分へ直し、最後に問題文で指定された1 MB＝1,000 KBで換算する。

QUESTION 273#center_style_original_202608_0121

同じ種類のセンサ3個を同時に稼働したとき、合計で1分当たり20 KBのデータが生じる。データ量はセンサ数に比例し、1 MB＝1000 KBとする。1日当たりの合計を100 MB以下にするため、設置できるセンサの最大数を次から選べ。

  1. 0

    9個

  2. 1

    3個

  3. 2

    10個

  4. 3

    11個

正答と解説を確認

正答2. 10個

解説

比例する量では、まず1個当たりの値を求める。上限以下の最大個数を求めるときは、上限÷1個分の商の整数部分を採る。

QUESTION 274#center_style_original_202608_0122

通信誤りがなく、同じビット列をそのままコピーする場合のデジタル情報の性質を次から選べ。

  1. 0

    デジタルデータは複製処理をするたびに少しずつ品質が下がる

  2. 1

    元と同一の内容を容易に複製・伝達できる

  3. 2

    一度保存すると内容を変更できない

  4. 3

    デジタル情報は紙やディスクのような物理的な形を持つ情報に限られる

正答と解説を確認

正答1. 元と同一の内容を容易に複製・伝達できる

解説

0と1の列として表された内容を誤りなく複製すれば、元と同一のデータを多数作り伝達可能になる。同じビット列を正しく複製すれば元とコピーは一致し、アナログ複写のような世代ごとの劣化は必須とはいえない。

QUESTION 275#center_style_original_202608_0129

4ビットの2の補数表現で正数0101と0100を加え、4ビットを超える桁は捨てる。得られるビット列と符号付きオーバフローの有無の組合せを次から選べ。

  1. 0

    1001・オーバフローあり

  2. 1

    1001・オーバフローなし

  3. 2

    0001・オーバフローあり

  4. 3

    1111・オーバフローなし

正答と解説を確認

正答0. 1001・オーバフローあり

解説

nビットの2の補数で表せる範囲は−2^(n−1)～2^(n−1)−1である。4ビットでは−8～7なので、5＋4＝9は範囲外となる。同符号の数を足したのに結果の符号が変わったことも、符号付きオーバフローを見抜く手掛かりになる。

QUESTION 276#center_style_original_202608_0139

1秒間に30枚のフレームを表示する30 fpsの動画を20秒間再生する。必要なフレーム数を次から選べ。

  1. 0

    600枚

  2. 1

    900枚

  3. 2

    1800枚

  4. 3

    50枚

正答と解説を確認

正答0. 600枚

解説

一定のフレームレートの動画では、総フレーム数＝fps×秒数で求める。30 fpsは1秒当たり30枚という意味なので、20秒では30×20＝600枚になる。分で与えられた時間は先に秒へ直す。

QUESTION 277#center_style_original_202608_0143

  1. 0

    5通り

  2. 1

    32通り

  3. 2

    10通り

  4. 3

    25通り

正答と解説を確認

正答1. 32通り

解説

nビットの各桁が独立に0または1を取るなら、組合せは2×…×2＝2ⁿ通りである。5ビットでは32通りになる。

QUESTION 278#center_style_original_202608_0149

センサが検出する75種類の状態へ、それぞれ異なる固定長のビット列を割り当てる。必要な最小ビット数を次から選べ。

  1. 0

    6ビット（64通り）

  2. 1

    75ビット（状態数と同じ長さ）

  3. 2

    8ビット（256通り）

  4. 3

QUESTION 279#center_style_original_202608_0150

7ビットのデータ1010110の右端に、受信時の誤り検出に使う偶数パリティビットを1ビット付加する。完成する8ビット列を次から選べ。

  1. 0

    10101101

  2. 1

    01010110

  3. 2

    10101100

  4. 3

    10101110

正答と解説を確認

正答2. 10101100

解説

偶数パリティでは、データと付加ビットを合わせた1の個数を偶数にする。元の1が偶数個なら0、奇数個なら1を付ける。単純なパリティ検査は1ビットの反転を検出できるが、偶数個のビットが反転すると見逃す場合がある。

QUESTION 280#center_style_original_202608_0151

記号A、B、Cの出現確率がそれぞれ0.6、0.3、0.1である。Aを0、Bを10、Cを11と符号化するとき、1記号当たりの平均符号長を次から選べ。

  1. 0

    1.4ビット

  2. 1

    1.7ビット

  3. 2

    2.0ビット

  4. 3

    2.6ビット

正答と解説を確認

正答0. 1.4ビット

解説

平均符号長は、各記号の出現確率×符号長を合計して求める。出現頻度の高い記号へ短い符号を割り当てると、固定長で表す場合より平均データ量を減らせることがある。
