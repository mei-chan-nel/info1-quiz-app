QUESTION 361#center_style_original_202608_0382

6ビットの2の補数表現で表せる10進整数の範囲を次から選べ。

  1. 0

    0～63

  2. 1

    −31～31

  3. 2

    −32～31

  4. 3

    −64～63

正答と解説を確認

正答2. −32～31

解説

2の補数では0を一通りだけ持ち、負側の端が正側より1だけ大きい。nビットなら最小値は−2ⁿ⁻¹、最大値は2ⁿ⁻¹−1と覚える。

QUESTION 362#center_style_original_202608_0383

4ビットの2の補数表現で1101と0010を加え、4ビットを超える桁を捨てる。得られるビット列と10進数としての値の組合せを次から選べ。

  1. 0

    1111・15

  2. 1

    1011・−5

  3. 2

    0001・1

  4. 3

    1111・−1

QUESTION 363#center_style_original_202608_0411

連続的な色調を持つ写真と、拡大しても輪郭を滑らかに保ちたい単純な企業ロゴを保存する。一般に適した画像表現の組合せを次から選べ。

  1. 0

    写真はベクタ画像、ロゴはラスタ画像

  2. 1

    写真もロゴもラスタ画像

  3. 2

    写真もロゴもベクタ画像

  4. 3

    写真はラスタ画像、ロゴはベクタ画像

正答と解説を確認

正答3. 写真はラスタ画像、ロゴはベクタ画像

解説

写真の細かな色は画素、ロゴの輪郭は座標と曲線で示すと各用途の長所を生かせる。複雑な写真をベクタで示すのは一般に非効率で、ロゴをラスタだけにすると拡大で輪郭が粗くなり得る。

QUESTION 364#center_style_original_202608_0412

横800画素、縦600画素、1画素24ビットの非圧縮画像について、1画素のビット数を保ったまま横と縦の画素数をそれぞれ2倍にした。付加情報を無視したデータ量の倍率を次から選べ。

  1. 0

    4倍

  2. 1

    1倍

  3. 2

    2倍

  4. 3

    8倍

正答と解説を確認

正答0. 4倍

解説

非圧縮画像のデータ量は「横画素数×縦画素数×1画素当たりビット数」で決まる。横と縦を各2倍にすると画素数は2×2＝4倍になり、色深度が同じならデータ量も4倍になる。

QUESTION 365#center_style_original_202608_0413

一般的なBMP画像ファイルの特徴として最も適当なものを次から選べ。

  1. 0

    画素ではなく線や図形の式を保存するベクタ形式が基本で、拡大しても輪郭が荒れない

  2. 1

    画素データを非圧縮で格納する形式がよく使われ、同条件の圧縮画像より大きくなりやすい

  3. 2

    写真の細部を捨てる非可逆圧縮が標準で、JPEGと同じ方法で容量を小さくする

  4. 3

    色数にかかわらず1画素を1ビットで保存するので、写真でも容量を抑えられる

正答と解説を確認

正答1. 画素データを非圧縮で格納する形式がよく使われ、同条件の圧縮画像より大きくなりやすい

解説

画像形式は、画素を並べるラスタ形式か、図形を式で表すベクタ形式か、さらに圧縮方法は何かを分けて比べる。BMPはラスタ形式で、非圧縮で使われることが多いため扱いは単純だが容量は大きくなりやすい。

QUESTION 366#center_style_original_202608_0418

アプリケーションがプリンタごとの制御命令を個別実装せず、OSの共通印刷機能を呼び出して印刷できるようにする仕組みを次から選べ。

  1. 0

    OSの共通印刷インタフェースと、機種固有のデバイスドライバ

  2. 1

    アプリが各機種の制御命令を直接埋め込み、OSとドライバを使わない方式

  3. 2

    印刷待ちデータを一時保存するスプーラだけで、機種固有命令への変換を行わない方式

  4. 3

    全プリンタの物理構造が同一であると仮定し、差異を処理しない方式

正答と解説を確認

正答0. OSの共通印刷インタフェースと、機種固有のデバイスドライバ

解説

OSが共通の操作方法を示し、ドライバが機種固有の命令へ変換することで、アプリはプリンタごとの違いを意識せず印刷できる。この役割分担を抽象化という。

QUESTION 367#center_style_original_202608_0419

一つのCPUで複数のプロセスを動かすOSが、CPUを使うプロセスを短い時間単位で切り替える主な目的を次から選べ。

  1. 0

    各プロセスの命令を一つのプログラムへ結合し、同時に実行する

  2. 1

    起動した順に、一つのプロセスを終了まで連続実行してから次へ移る

  3. 2

    プロセスごとに専用CPUが物理的に追加された状態を作る

  4. 3

    複数の処理が見掛け上並行して進むよう、CPU時間を配分する

正答と解説を確認

正答3. 複数の処理が見掛け上並行して進むよう、CPU時間を配分する

解説

一つのCPUが同時に実行できる命令列は限られるが、短い時間片ごとに実行対象を切り替えると複数処理が並行して進むように見える。切替え時には実行位置などの状態を保存・復元するため、毎回最初からやり直すわけではない。

  3. 2

QUESTION 370#center_style_original_202608_0432

一般的なパーソナルコンピュータにおけるSSDとRAMの役割・性質の違いを次から選べ。

  1. 0

    SSDは揮発性の主記憶、RAMは不揮発性の補助記憶である

  2. 1

    SSDもRAMも電源断で内容を失う揮発性記憶で、用途も同じである

  3. 2

    SSDもRAMも電源断後に内容を保持する不揮発性記憶で、用途も同じである

  4. 3

    SSDは不揮発性の補助記憶、RAMは揮発性の主記憶である

正答と解説を確認

正答3. SSDは不揮発性の補助記憶、RAMは揮発性の主記憶である

解説

記憶装置は、電源断後に内容が残るかと、処理中にどの役割を担うかを分けて比べる。一般的なSSDは不揮発性でファイル等を長期保存する補助記憶、RAMは揮発性でCPUが実行中に使う主記憶である。速度だけで主記憶・補助記憶を分類しない。
