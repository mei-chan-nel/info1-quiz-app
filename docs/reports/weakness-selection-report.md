2. 計算・抽選

`attempts > correct`の異なる問題IDが履歴全体で5題以上なら解放します。正答へ回復しても累積値は残り、履歴削除で再ロックされます。解放状態や苦手度スコアの新規永続保存はありません。

初期値は直近誤答1.0、誤答後正答0.3、それ以外0。`top5`だけを有向辺として均等配分し、`R = 0.3s + 0.6Pᵀs + 0.1(Pᵀ)²s`をMapで計算します。複数経路と元問題への戻りを加算し、3段階目には進みません。最後に未解答1.0、直近誤答0.1、その他の解答済み0.05を乗じます。

全分野から伝播した後、既存の分野・回答状況・計算問題の絞り込みを通った候補から、最終重みに比例して重複なしで選びます。正の重みの候補を使い切った場合だけ、残りの同条件候補から既存の通常抽選で不足分を埋めます。通常出題の直近解答減衰や分野別補正を苦手抽選へ重ねていません。

3. UI

詳細設定内の順番を「出題方法 → 回答状況 → 計算問題 → 学習記録を見る」にしました。未解放時だけ`🔒 苦手重点出題（誤答5題以上で解放）`を選択不可で表示します。解放後は`苦手重点出題`だけを表示します。保存値が苦手重点でも未解放なら通常出題に戻して保存します。

閉じた詳細設定には出題方法・回答状況・計算問題を各1行で表示し、設定変更時に更新します。開いている間は要約を非表示にします。既存の回答状況と計算問題の選択は自動変更しません。
